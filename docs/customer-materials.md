# 고객 자료와 작성 양식

- 고객 등록/수정에서 사업자등록번호(숫자 10자리), 사업자등록증(PDF/이미지), 기타 참고자료를 입력·첨부한다. 첨부 실패 시 고객은 보존하고 저장하지 못한 파일만 재시도한다.
- 고객 상세와 자료실은 같은 비공개 고객 자료를 보여준다. 파일당 최대 4MB, 형식은 PDF·JPG/PNG/WebP·XLSX/CSV·TXT/MD다. 큰 파일은 분할 또는 축소해서 등록한다.
- 자료실의 고객 작성용 Excel 다운로드를 고객에게 전달하고, 작성본은 고객 선택 → 고객 작성 Excel → 업로드로 등록한다. 원본 다운로드와 추출 내용 미리보기를 제공한다. 자동으로 고객/제품 정보를 덮어쓰지는 않는다.
- 양식은 작성안내, 고객브랜드, 제품정보, 제작요청(5세트), 자료목록의 5개 시트로 구성한다. 계약 기준 수량은 별도로 확정한다. 매크로·수식은 실행하지 않는다.
- 같은 고객의 프로젝트를 선택해 참고자료·작성본을 자료로 복사할 수 있다. 복사 후 프로젝트 자료 탭에서 내용을 검토한다. 사업자등록증은 복사 대상에서 제외하고 제작 입력에 자동 포함하지 않는다.
- 모든 업로드는 고객 ID를 확인한 후 Supabase 비공개 Storage에 저장한다. 파일 다운로드와 양식 다운로드에는 운영자 로그인이 필요하다.
- 최초 빈 양식 파일: [customer-marketing-intake-v1.xlsx](templates/customer-marketing-intake-v1.xlsx). 앱에서는 서버의 최신 양식을 생성해 내려받는다.
- 이 앱에 올린 파일이 현재 대화에 자동 첨부되는 것은 아니다. 대화에서 검토를 요청하려면 다운로드한 작성본을 채팅에 첨부하거나 앱의 프로젝트 제작 자료로 명시적으로 연결한다.
