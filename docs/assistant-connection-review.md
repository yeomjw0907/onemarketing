# 업무 도우미 오류 점검과 연결 개선안

2026-10-20.

## 수정한 오류

- 선택 답변 접수 후 응답 유실 시, 고객 이름·단가가 변경되면 동일 요청 재시도도 실패했다. 최초 제출은 현재 데이터를 검증하고, 이미 접수한 동일 요청은 원래 질문의 선택값으로 내용 일치를 검사해 기존 접수 결과를 반환한다.
- 오래된 대기·실행 요청 정리가 PC의 요청 수신에 의존했다. PC가 중단되어도 대시보드 조회와 새 요청 단계에서 만료 상태를 정리한다. 실행 lease 만료와 5분 이상 대기한 요청은 자동 재실행하지 않는다.
- 일반 선택 질문의 모든 선택지가 같으면 버튼은 생기지만 답변을 제출할 수 없었다. 서로 다른 선택지가 최소 두 개 있어야 질문을 노출한다.
- 기기가 온라인이기만 하면 설정 목록에 연결됨으로 표시됐다. 준비 완료·로그인 필요·연결 오류·준비 중을 구분한다.

## PC 방식의 UX 개선

웹페이지가 미설치 프로그램을 조용히 설치하거나 실행할 수는 없다. Windows 연결 프로그램을 최초 한 번 설치하고 전용 URI를 등록하면, 이후 대시보드 연결 버튼으로 해당 프로그램을 실행할 수 있다. 브라우저의 앱 열기 확인창은 표시될 수 있다. 자동 시작은 최초 설치 시 사용자가 선택하도록 한다.

제안 흐름: 연결 프로그램 설치 → ChatGPT 로그인·PC 연결 승인 → 이후 로그인 시 자동 실행 → 대시보드에서 연결 상태 확인 / 필요할 때 연결 프로그램 열기. 모바일은 이미 연결된 PC의 상태를 보여주며 PC가 꺼져 있으면 모바일 버튼만으로 켤 수 있다고 안내하지 않는다.

구현 시 전용 URI는 시작·연결 요청만 처리하고, 주소는 원케이션 허용 목록에 제한한다. 사용자 확인 없이 기존 연결 계정을 교체하지 않으며, 토큰을 URI에 넣거나 원격 명령을 실행하지 않는다. 중복 실행 방지와 연결 상태에 따른 설치 안내가 필요하다.

이번 변경에서는 설치 프로그램·URI 등록·로그인 시 자동 시작을 구현하거나 PC 설정에 추가하지 않았다.

## 공식 OAuth 대안

현재 OpenAI 문서는 `Sign in with ChatGPT`를 제공한다. 신원 로그인과 ChatGPT 구독 사용 권한은 서로 다르며, 로그인만으로 모델 호출 권한이 생기지 않는다. 상용 웹 연동은 일부 선정 파트너 대상이고 구독 사용은 오픈소스 파트너 및 선정된 비공개 클라이언트 대상으로 안내돼 있다. 원케이션이 승인된 상태라고 가정해서는 안 된다.

문서는 기존 App Server 인증을 로컬·오픈소스 앱과 구분하고 상용·호스팅 서비스용 인증으로 허용하지 않는다고 명시한다. 기존 PC 커넥터의 외부 서비스 확장 경로는 이 조건을 먼저 확인해야 한다. 장기적으로는 원케이션의 OAuth 클라이언트와 구독 사용 승인을 받아 웹에서 연결하는 방식이 더 단순하다. 승인 전에는 정식 웹 OAuth가 바로 사용 가능하다고 약속하지 않는다.
