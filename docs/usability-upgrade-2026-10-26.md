# 모바일·광고주 등록·역할별 화면 개선

2026-10-26. 기존 파란색(#3182f6), 타이포그래피와 버튼·패널 라디우스를 유지하며 탐색 → 상세 → 로그인/지원 → 운영의 이동을 개선했다.

## 1. 모바일 탐색과 상세

- 메인 현황을 한 줄로 압축하고 업종은 가로로 탐색한다. 상세 조건·모집 상태·정렬은 모바일 필터에서 선택한다.
- 390×844 브라우저에서 첫 캠페인 시작 위치를 기존 806px에서 484px로 줄였다. 첫 제목은 655px에 표시됐고 리워드도 첫 화면에서 확인할 수 있었다. 수치는 격리 데이터와 해당 뷰포트 기준이다.
- 채널 탭 높이는 27px에서 44px로 확대했다. 카드 본문과 신청 현황의 작은 글씨를 키웠다.
- 미등록 이미지에는 오류 아이콘 대신 브랜드 이니셜을 표시한다. 실제 브랜드 사진을 임의로 만들지 않는다.
- 상세 하단에는 리워드와 로그인/지원/나의 활동 버튼을 고정한다. 입력 중에는 키보드와 충돌하지 않게 숨긴다. 비회원 상세 원문 차단은 유지한다.
- 목록의 검색·필터·정렬·페이지를 URL에 저장하고 상세에서 돌아올 때 스크롤 위치를 복원한다.

## 2. 로그인

- 광고주 / 체험단을 대칭 선택으로 정리하고 세로 입력 폼으로 변경했다.
- 캠페인에서 온 사용자는 체험단 로그인을 먼저 보여준다. 광고주 작성 화면에서 온 사용자는 광고주 로그인을 먼저 보여준다.
- 광고주 등록 화면으로 복귀하는 경로도 허용하되 임의 외부 주소는 허용하지 않는다.
- 역할 전환 시 다른 역할의 캠페인 복귀 정보가 남는 문제를 수정했다. 실제 카카오 계정으로 외부 OAuth 인증을 실행한 것은 아니며 기존 인증 모듈을 재사용한다.

## 3. 광고주 등록

상품 선택 → 기본 정보 → 인원·일정·가이드 → 확인 순서다. 초안과 장바구니는 이 브라우저에 저장하며 기기 간 동기화는 제공하지 않는다. 기존 구성 삭제 없이 장바구니 항목을 수정할 수 있다. 수정 중에는 오래된 구성으로 주문하지 못한다.

견적은 기존 가격 계산 함수를 재사용한다. 패키지 포함 항목, VAT, 대행 범위와 일정 조건을 유지한다. 주문 접수와 입금 확인은 구분한다.

대표 이미지는 광고주 로그인 후 JPG·PNG·WebP 파일(3MB 이하)을 업로드할 수 있다. 서버에서 실제 이미지 형식을 검증하고 크기를 제한해 WebP로 다시 저장한다. 일일 업로드 수는 계정당 30장이다. 결제 확인 전 이미지 원문은 업로드한 광고주와 관리자만 열람할 수 있다. 결제된 공개 캠페인에 연결되면 공개하며 테스트·미리보기 상태로 바꾸면 공개 이미지 응답도 차단한다. 다른 계정의 비공개 업로드를 주문에 연결할 수 없다.

## 4. 마이페이지

- 광고주: 입금 대기·선정·검수·환불을 처리 대기 목록에서 바로 연다. 운영 대행 캠페인은 광고주에게 담당자 전용 선정·검수 할 일로 표시하지 않는다.
- 관리자: 입금 확인·환불 검토와 송금 기록·검수·선정을 모은다. 버튼은 기존 권한 검증과 처리 폼으로 연결되며 송금이나 선정 권한을 확대하지 않는다.
- 지원자 화면: 이름/지원 내용 검색과 상태 필터를 추가한다. 검수 목록에서 열면 제출한 지원자로 필터링한다. 연락처·배송지·정산 계좌는 기존대로 비교 CSV에 포함하지 않는다.
- 체험단: 참여 수락·게시물 제출·수정 후 재제출이 필요한 캠페인을 기한 순으로 모은다. 해당 캠페인의 실제 폼으로 이동한다. 기존 참여 제안·게시 작업·리워드 내역의 바로가기를 제공한다.
- 관리자 ‘공개 캠페인 정보’에서 공개 모집 / 테스트·미리보기(공개 목록 제외)를 선택한다. 일반 광고주는 관리자가 제외한 캠페인을 다시 공개할 수 없다. 운영 데이터의 공개 상태를 일괄 변경하지 않았다.

## 검증

- 전체 자동 테스트 275개 통과 후 추가한 공개 범위 권한을 포함해 관련 테스트 11개를 다시 통과했다.
- 최종 프로덕션 빌드와 타입 검사 통과.
- 격리 스키마·격리 저장소에서 HTTP 주문·입금·지원·선정·검수·환불·MCP/OAuth·15개 페이지·이미지 접근 권한·테스트 캠페인 비공개와 복구 검증 통과.
- 실제 브라우저에서 모바일 필터/목록 복귀, 로그인 역할 선택, 초안 새로고침 복원, 파일 업로드/미리보기, 장바구니 구성 수정, 주문 접수와 장바구니 비우기, 세 역할의 처리 대기 이동, 관리자 공개 범위 저장을 확인했다.
- 모바일 체험단·관리자·작성 화면의 가로 넘침이 없음을 확인했다. 실제 결제·송금·문자 발송은 실행하지 않았다. 검증용 캠페인과 업로드는 격리된 환경에서만 생성했다.
