# 신청 페이지 채널 로고

2026-10-15 공식 배포 자료에서 받은 원본을 채널 식별 용도로 사용한다. 색상·형태를 수정하지 않고 비율을 유지한다.

| 파일                          | 공식 출처                                                                                                                                                         |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `public/brands/naver.png`     | [NAVER 브랜드 리소스](https://www.navercorp.com/company/brandGuide), 페이지의 `/img/pc/logo-type-green.png`                                                       |
| `public/brands/instagram.svg` | [Instagram 브랜드 리소스](https://www.meta.com/brand/resources/instagram/instagram-brand/), 공식 ZIP의 `01 Static Glyph/03 Black Glyph/Instagram_Glyph_Black.svg` |
| `public/brands/facebook.png`  | [Facebook 로고](https://www.meta.com/brand/resources/facebook/logo/), 공식 ZIP의 `Logo/Primary Logo/Facebook_Logo_Primary.png`                                    |
| `public/brands/linkedin.png`  | [LinkedIn 다운로드](https://brand.linkedin.com/downloads), 공식 `in-logo.zip`의 `in-logo/LI-In-Bug.png`                                                           |
| `public/brands/youtube.png`   | [YouTube 브랜드 리소스](https://www.youtube.com/howyoutubeworks/resources/brand-resources/), 공식 페이지의 gstatic 파비콘                                         |

입력 인터랙션은 [TDS TextField](https://tossmini-docs.toss.im/tds-mobile/components/TextField/text-field/)와 [TDS Menu](https://tossmini-docs.toss.im/tds-mobile/components/menu/)를 참고한 자체 구현이다. 이메일 추천 방식은 이 프로젝트의 구현이며 토스 앱의 실제 이메일 입력 흐름을 복제했다고 주장하지 않는다.
