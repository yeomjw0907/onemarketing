# 원케이션 처리 상태 Orb

`BrandOrb`는 thinking-orbs 0.3.2를 감싸는 공통 클라이언트 컴포넌트다. 원케이션 블루 `#3182F6`, 속도 0.85, 밝은 화면 테마를 기본으로 사용한다. `active`가 false이면 렌더링하지 않는다. 본문 상태는 20px, 독립 로딩 화면은 64px을 사용한다.

- 관리자: 실행 중인 AI 작업에만 검색·작성·검증·미디어 제작 상태를 연결한다. 큐 대기, 승인 대기, 상태 확인 필요, 완료, 실패에는 표시하지 않는다. 초기 로그 조회 중에는 연결 상태를 사용하고 조회 오류가 발생하면 숨긴다.
- 고객: 보고 화면을 실제로 불러오는 Next loading 경계와 엑셀 응답을 기다리는 동안 표시한다. 캠페인 제작 중이라는 이유만으로 계속 표시하지 않는다. 다운로드는 중복 요청을 막고 실패 시 오류와 재시도를 제공한다. JavaScript가 없으면 기존 다운로드 링크로 동작한다.
- 참여자: 작업 목록, 로그인 상태, 게시 자료 파일을 실제로 조회하는 동안 표시한다. 운영자 승인이나 자료 준비를 기다리는 상태에는 표시하지 않는다.

라벨을 제공하면 polite 상태 안내로 노출하고, 주변에 안내 문구가 있으면 Orb 자체는 장식 요소로 숨긴다. 라이브러리의 움직임 줄이기 설정, 화면 밖 및 비활성 탭 정지 기능을 유지한다. 실제 공급사 진행률이 없는 경우 진행률을 추정하지 않는다.

검증: 프로덕션 빌드, 자동 테스트 191개 통과. 운영 데이터와 분리된 임시 QA 스키마에서 1440px PC와 390px 모바일 브라우저 확인. 색상 픽셀, 애니메이션, 움직임 줄이기, 비실행 상태 숨김, 완료·오류 시 숨김, 실제 엑셀 생성과 다운로드, 중복 클릭 방지, 가로 넘침 없음 확인. 외부 메시지·송금·유료 AI 호출은 실행하지 않았다. 임시 QA 스키마와 인증 정보는 검증 후 제거했다.
