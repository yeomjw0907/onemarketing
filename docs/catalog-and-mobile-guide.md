# 고객·제품 복원과 모바일 게시 가이드

## 관리자

고객·제품 → 삭제된 목록에서 삭제일, 고객명·제품명, 고객 연결을 확인하고 검색·복원한다. 고객이 삭제된 상태에서는 하위 제품을 먼저 복원할 수 없다.

고객 복원은 해당 고객과 같은 회차에 함께 삭제된 제품만 복원한다. 삭제 시 `deletedWithCustomerId`, `deletedWithCustomerAt`을 기록해 독립 삭제와 구분한다. 이전 버전에서 삭제된 항목은 고객·제품의 삭제 시각과 삭제자가 정확히 일치하는 경우에만 함께 복원한다. 따로 삭제한 제품은 고객 복원 후 개별 복원한다.

삭제·복원은 버전 검사, 고객·제품 공통 잠금, 명령 중복 방지, 감사 기록을 사용한다. 과거 프로젝트·견적·정산 데이터는 변경하지 않는다. 복원 후 새 견적과 제품 등록 등에 다시 사용할 수 있다.

## 참여자

참여 가이드 `/participants/guide` 및 나의 작업 → 게시 작업에서 아래 순서를 안내한다.

1. 이미지·영상을 확인하고 저장. 이미지 순서는 기존 제작 이미지 순서를 사용한다. 파일 저장, 안전한 이미지 미리보기와 지원 기기의 파일 공유 메뉴를 제공한다.
2. 광고 표시를 포함한 전체 원고 복사. 클립보드가 차단되면 원고를 자동으로 펼치고 선택해 직접 복사할 수 있게 한다.
3. 네이버 앱/웹 열기. Android Intent와 iOS 네이버 앱 URL Scheme은 네이버 공식 inappbrowser v6 명세를 따른다. PC에서는 웹으로 연다. 웹·앱 설치 대안도 제공한다. 특정 편집기를 자동 조작하거나 자동 게시하지 않는다.
4. 공개 게시 후 공유 메뉴에서 링크를 복사해 기존 제출 폼에 제출.

승인된 최신 자료와 본인 작업의 파일만 접근할 수 있다. `?preview=1`은 같은 인증·소유권 검사를 거치며 PNG/JPEG/WebP/GIF/MP4만 inline으로 제공한다. HTML/SVG 등은 미리보기로 전환하지 않는다. 비공개·no-store와 nosniff를 유지한다.

사진 앱으로 자동 저장 완료를 추정하지 않는다. Web Share 지원·사진 저장 위치는 OS와 브라우저에 따라 다르며 파일 준비 후 별도 클릭으로 공유 메뉴를 연다. 큰 파일(25MB 초과)은 일반 파일 저장을 사용한다. 실제 앱 전환·사진 저장은 설치된 휴대폰에서 추가 확인이 필요하다.

공식 참고: https://developers.naver.com/docs/utils/mobileapp/ , https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share

검증: 고객 연쇄 복원·독립 제품 복원·이전 삭제 이력 호환·버전 충돌·부모 삭제 차단·견적 재사용, Android/iOS/PC 링크를 테스트했다. 격리 브라우저에서 복원, 실제 파일 다운로드·inline 미리보기, 다른 작업 파일 접근 403, 광고 문구 포함 복사·실패 시 직접 복사, 파일 공유 전달(브라우저 API 대체), 1440/390/360px 화면을 확인했다. 실제 참여자에게 알림을 발송하거나 운영 고객을 삭제·복원하지 않았다.
