# 계정별 초안·장바구니·관심 캠페인 연동

2026-10-26. 광고주의 캠페인 초안·장바구니와 역할별 관심 캠페인을 계정에 저장해 기기를 바꿔도 이어서 사용할 수 있게 했다.

## 저장과 복원

- 광고주 작성 화면에 들어오면 계정의 초안·작성 단계·수정 중인 장바구니 항목을 복원한다. 입력 중인 한 글자 제목이나 미완성 이미지 주소도 초안으로 저장할 수 있다. 장바구니와 주문은 기존 상품 검증을 통과해야 한다.
- 변경 후 짧은 지연을 두고 저장하며 저장 중/완료/실패를 표시한다. 새 기기에서 열거나 기존 화면으로 포커스를 돌리면 계정의 최신 내용을 읽는다.
- 초안·장바구니를 하나의 버전으로 저장해 장바구니 항목과 수정 대상이 서로 어긋나지 않게 한다. 다른 기기에서 이미 변경했다면 409 충돌로 멈추며 계정 내용을 다시 읽거나 명시적으로 현재 내용으로 저장할 수 있다.
- 로그인 전에는 기존처럼 브라우저에 작성한다. 이전 브라우저 내용은 로그인한 계정에 자동으로 덮어쓰지 않으며 ‘브라우저 내용을 계정으로 가져오기’로 옮긴다. 대체될 범위를 화면에 안내한다.
- 저장 실패 시 계정별 임시 사본을 이 브라우저에 남겨 다시 열었을 때 복구한다. 서버 버전이 바뀌었으면 덮어쓰기 전 충돌을 안내한다. 다른 계정으로 전환하거나 로그아웃하면 이전 계정 내용은 화면에 표시하지 않는다.

## 주문과 관심 캠페인

- 계정 장바구니 주문은 서버의 저장된 구성을 기준으로 가격을 다시 계산한다. 주문 접수와 장바구니 비우기를 하나의 DB 트랜잭션에서 수행한다. 다른 기기의 오래된 장바구니는 다시 주문할 수 없다.
- 응답 유실 뒤 같은 주문 요청을 재시도하면 기존 주문을 돌려준다. 이 기능의 주문은 계좌이체 접수이며 입금 확인·실제 송금은 기존 운영 절차를 유지한다.
- 별도 MCP 주문은 사용자가 웹에서 보관한 다른 장바구니를 임의로 비우지 않는다.
- 관심 캠페인은 계정별 항목 추가/해제로 저장한다. 초안 저장 버전과 분리했으므로 관심 표시 변경이 작성 화면의 저장 충돌을 일으키지 않는다. 기존 브라우저 관심 항목은 선택해서 계정으로 가져올 수 있다.
- 체험단·광고주·관리자 계정 공간을 구분한다. API는 쿠키 세션에서 소유자를 결정하며 클라이언트가 다른 계정의 상태를 지정할 수 없다. 저장 도중 로그인 계정이 바뀌면 이전 내용의 저장을 거부한다.

## 구현

`account_state` 테이블에 역할·계정·저장 항목을 복합 키로 사용하고 RLS를 적용했다. anon/authenticated 역할의 직접 테이블 접근을 차단하고, 검증된 서버 API만 읽고 쓴다. 배포 전 동일 migration을 운영 DB에 적용하고 추적 테이블에 기록했다. 기존 계정·주문·캠페인 데이터는 일괄 수정하거나 삭제하지 않았다.

`/api/account-state`의 GET은 builder/favorites를 반환하고 POST는 버전 기반 저장, 관심 추가/해제·가져오기와 계정 장바구니 주문을 수행한다. 응답은 private/no-store다. UTF-8 장문 가이드가 담긴 10개 장바구니도 저장할 수 있도록 요청 크기를 제한하되 충분히 확보했다.

## 검증

- 전체 자동 테스트 279개 통과. 추가 계정 저장 테스트에서 소유자·역할 격리, 미완성 초안 저장, 동시 수정 충돌, 주문 원자성·중복 방지와 관심 항목 분리를 확인했다.
- 격리 DB·저장소의 실제 HTTP 주문·지원·선정·검수·환불·MCP/OAuth 및 계정 저장·소유자 바꿔치기 거부·오래된 버전 거부·체험단 관심 항목·장문 10개 장바구니를 검증했다.
- 저장소가 독립적인 두 브라우저로 초안 이어쓰기, 장바구니 공유, 양쪽 장바구니 초기화, 관심 추가/해제 전파, 충돌 불러오기/덮어쓰기, 네트워크 저장 실패 복구, 브라우저 초안 가져오기, 계정·로그아웃 격리, 최초 읽기 실패 재시도와 계정 전환 시 주문 접수 정보·개인 지원 상태 초기화까지 14개 항목을 확인했다.
- 최종 타입 검사·프로덕션 빌드 후 main push와 원격 CI·배포 상태를 확인한다.

## 가격·서비스 소개·배너 제안

이 배포는 계정 연동을 반영한다. 가격 공개 정책과 메인 배너는 아직 변경하지 않았다.

비회원에게는 상품의 구성·결과물·진행 기간과 서비스 이용 방법을 설명하고, 정확한 단가·최종 견적은 광고주 로그인 후 보여주는 구성을 추천한다. 체험단이 확인하는 캠페인 리워드는 상품 판매 가격과 구분해야 한다. 공개 표시를 바꾸더라도 가입한 사람이 가격을 외부에 공유하는 것까지 막을 수는 없으므로 가격 비밀 유지보다는 이용 흐름을 기준으로 정하는 편이 좋다.

메인은 캠페인 탐색을 중심으로 두고 낮은 일러스트 배너를 더한다. 서비스 소개 페이지는 광고주/체험단의 역할, 셀프 모집/제작·게시/대행의 차이, AI·MCP와 일반 웹 등록을 설명하는 용도로 구성한다.

이미지 생성 모델의 built-in image_gen으로 배너 시안을 생성했다. 검토용 파일과 프롬프트는 `outputs/service-banner-concept.png`, `outputs/service-banner-concept.md`에 있으며, 배포 자산에는 포함하지 않았다. 배너 문구는 이미지 안에 넣지 않고 HTML로 올려 모바일과 접근성에 맞춰 조정하는 방향이다.
