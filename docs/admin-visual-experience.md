# 관리자 화면 시각화·정보 위계 개선

운영 현황에서 사용한 원케이션 블루, 절제된 표면, 작은 보조 설명, 명확한 수량 위계를 관리자 화면으로 확장했다. 공통 Button·Tabs를 재사용하고 CSS 모듈 범위 안에서만 스타일을 적용한다. 운영 데이터 구조·가격·정산·승인 동작은 바꾸지 않는다.

- 대시보드 제목은 게시 유지 이상 → 마감 지연 → 오늘 마감 → 검수·수정 대기 → AI 작업 → 일반 현황 순으로 실제 상황을 안내한다. 날짜는 기존 상단 표시를 사용하고 오늘 마감과 지연을 구분한다. 관련 캠페인·복구 화면으로 이동하는 바로가기를 제공한다. 상태 근거 없이 ‘순조롭다’고 표시하지 않는다.
- AI 비용은 기존 청구/추정/환율 집계를 그대로 사용한다. 선택한 필터 기준으로 제작 종류별 실제 USD 청구와 사용량 기반 추정을 별도 막대로 보여준다. 수동 확정 원화와 금액 미확인을 USD 막대에 합치지 않는다. 기존 종류별·프로젝트별·일별·월별·개별 요청 표, 근거, 페이지 이동은 ‘청구·사용량 상세 내역’에서 유지한다. 긴 계산 설명은 별도 펼침 영역에 보존한다.
- 고객·제품 목록은 각 항목의 정보와 수정·삭제 동작을 같은 영역에 묶는다. 고객별 진행 캠페인과 전체 요약은 보류·완료·취소를 제외하는 동일한 기준이다. 기존 삭제 확인·복원·보고 링크·자료 관리 흐름을 유지한다.
- 계약은 회차당 공급가액/VAT·제공 구성·시작 회차를 함께 보여주고 기존 프로젝트 시작 기능으로 연결한다. 프로젝트 목록은 실제 게시 확인/취소 제외 작업 수를 막대로 보여주며 기존 검색·단계 필터·상세 이동을 유지한다.
- 참여자 목록과 가입·계정 검토는 탭으로 분리한다. 모바일 참여자 표는 카드 형태로 읽히도록 재배치하되 목록 전체 선택·개별 선택·최대 100명 제한·상세·삭제·복원 동작을 유지한다. 신청 검토 건수를 등록 참여자 숫자로 추정하지 않는다.
- 캠페인 운영은 실제 미배정 슬롯·검수/수정 대기·게시 확인·지급 완료 작업 수를 표시하고 해당 탭으로 연결한다. 검수·게시·자료실·설정에도 각 화면 범위의 실데이터 요약을 제공한다. 자료실에는 보관 → 프로젝트에 복사 → 제품 정보 확인 과정을 아이콘으로 안내한다.

검증: 전체 테스트 202개 통과, 최종 집계 보정 후 관련 테스트 재통과, 프로덕션 빌드 통과. 별도 QA 스키마를 사용해 관리자 10개 화면(운영 현황·고객·계약·프로젝트·참여자·자료실·검수·게시·캠페인 운영·설정)을 1440/1024/768/390/360px에서 검사했다. 가로 넘침·JavaScript 페이지 오류가 없었고 비용 필터/상세 표, 제목 바로가기, 고객·제품 수정 폼 진입, 계약 프로젝트 시작 폼 진입, 프로젝트 이동, 참여자 선택/검토 탭/상세 이동, 자료 내용 미리보기, 운영 요약 탭 이동, 상품 단가 폼 진입을 확인했다. 자료 다운로드·실제 승인·송금·메시지·유료 AI는 이번 UI 검수에서 실행하지 않았다. 검수 후 임시 QA 스키마와 로그인 정보를 제거했다.
