# 네이버 클립 동영상 업로드 조사

확인일: 2026-10-17. 대상은 현재 원케이션에서 제공하는 동영상 클립이며 사진·텍스트형 클립 게시물이나 네이버TV의 별도 업로드 화면과 구분한다.

## 공식 자료 확인

네이버 ‘클립 동영상 제작 방법’ 문서:
https://help.naver.com/service/30048/contents/24422?osType=COMMONOS&ostype=commonos

- 동영상 기본 정보는 커버 이미지, 본문, 카테고리, 공개 여부 등으로 구성된다. 공식 모바일 발행 화면에 별도 제목 입력칸은 없다. 제목을 별도 필수 필드로 만드는 대신 게시할 설명 본문을 준비해야 한다.
- 문서는 본문과 카테고리에 별표를 표시한다. 본문 설명 최대 300자, 해시태그 최대 5개를 안내하며, 공식 발행 화면의 입력 안내는 최소 10자를 표시한다. 따라서 본문을 생략하는 운영 흐름으로 설계하면 안 된다.
- 해시태그에는 #와 _ 외 특수문자·이모지를 포함하지 않는다. 문서는 해시태그 개수 자체가 추천·노출을 보장하지 않는다고 안내한다.
- 카테고리는 영상 주제와 가장 가까운 것을 선택한다.
- 광고·협찬이 포함된 콘텐츠는 해당 설정을 ON으로 한다. AI를 활용한 콘텐츠는 AI 활용 설정을 ON으로 한다.
- 본문의 일반 링크 기능은 지원하지 않는다. 별도의 ‘콘텐츠 링크’와 ‘정보 태그’ 기능은 구분해야 한다.
- 전체 공개로 게시해야 원케이션의 유지 조건에 부합한다.

## 현재 코드와 운영 권고

클립은 영상과 설명 원고 최신본 1개를 함께 검수한다. 설명 저장·내부 승인·참여자 전달·ZIP 내보내기에서 설명 10~300자와 해시태그 최대 5개를 확인한다. 문자 수는 앞뒤 공백을 정리한 본문의 공백·줄바꿈·해시태그를 포함하며 유니코드 코드 포인트로 센다. 네이버 앱에서의 최종 발행 결과 확인은 별도로 필요하다.

자동 생성은 게시할 설명과 내부 제작 메모를 분리한다. 참여자에게는 승인된 설명과 영상이 함께 전달되며 ‘클립 설명 복사’로 본문을 복사할 수 있다. 블로그용 마크다운 정리를 적용하지 않아 본문 첫머리의 `#광고`와 해시태그를 유지한다. 기존 영상만 승인된 작업도 새로 전달하려면 유효한 설명을 추가해 재승인해야 한다.

후속 보완 권고:

1. 제목은 내부 관리명/커버 문구와 구분하고 설명에 광고 표시와 캠페인 필수 정보를 유지한다. 길이·태그 검증이 내용의 정확성을 대신하지 않으므로 영상과 본문을 함께 내부 검수한다.
2. 키워드 조사·기획에는 후보별 검색 의도, 제품 관련성, 수집한 출처와 선정·제외 근거를 작성한다. 기획에서 수집하지 않은 출처를 인용하면 검증을 통과하지 못한다. 검색량·경쟁도 실측 API는 연결하지 않았으므로 웹 문맥 기반 추천을 실측 데이터로 표시하지 않는다. 기존 조사 결과는 자동으로 다시 생성하지 않는다.
3. 카테고리, 필요한 장소/정보 태그, 광고·협찬 설정, AI 활용 여부를 캠페인별로 명시해 참여자가 임의로 결정하지 않게 한다.
4. 실제 모바일 업로드 1건으로 입력 조건·표시 결과를 재확인한다. 공식 안내의 플랫폼 조건과 원케이션 내부 운영 조건은 구분해 관리한다.

## 디자인 변경

네이버 공식 favicon을 네이버 이동 버튼에 사용하고 브랜드 리소스의 Green `#03C75A`를 적용했다. 작은 흰 글자의 대비 문제를 줄이기 위해 버튼 문구는 어두운 색으로 표시한다. 공식 아이콘은 색상을 변경하지 않았다.

숫자 원형 배지는 제거하고 행동형 제목, 여백과 구분선으로 순서를 표현한다. 이는 기존 공통 컴포넌트와 디자인 토큰을 이용한 화면 정리이며 토스의 공식 디자인 규칙이라고 단정하지 않는다.
