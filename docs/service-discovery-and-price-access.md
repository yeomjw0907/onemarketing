# 서비스 탐색과 가격 공개 범위

## 화면 구성

- `/`: 짧은 서비스 배너 → 모집 현황·검색 → 업종과 채널 → 실제 캠페인 목록. 모바일에서 큰 홍보 영역이 목록을 과하게 밀어내지 않도록 배너를 줄인다.
- `/about`: 서비스 소개, 셀프 모집·콘텐츠 패키지·운영 대행의 차이, 진행 순서, 체험단과 AI 연결 안내.
- `/marketing`, `/marketing/legacy`: 광고주 세션이 없으면 금액 없는 상품 구성 안내. 광고주 세션이 있으면 기존 작성·견적·장바구니 화면.
- 캠페인 상세의 로그인 정책과 공개 리워드는 유지한다. 상품 판매 가격과 참여자 리워드는 다른 정보다.

## 접근 기준

Next 서버에서 광고주 세션을 검증한 뒤 가격 화면을 렌더링한다. 비회원, 체험단 단독 세션, 관리자 단독 세션은 상품 안내를 본다. 관리자는 기존 운영 화면에서 가격을 관리한다.

두 카탈로그 API도 광고주 세션을 확인하며 인증이 없으면 401을 반환한다. 공개 환불 안내와 배포용 Skill 문서의 고정 패키지 금액은 제거했다. 인증된 MCP 카탈로그 조회는 유지한다.

광고주 화면은 탭 복귀와 인증 변경 이벤트에 세션을 재확인한다. 확인 중 가격 영역을 가리고, 인증이 끊겼으면 공개 안내로 전환한다. 확인 중에는 작성 컴포넌트를 유지해 초안이나 업로드 상태를 잃지 않도록 한다.

화면·API의 가격 공개 정책이며 클라이언트 견적 계산 코드의 역공학 방지를 의미하지는 않는다. 가격 계산은 기존과 같이 최종 결제 시 서버에서 검증한다.

## 디자인 참고

2026-10-26 [마플 홈페이지](https://www.marpple.com/kr/)를 브라우저로 확인했다. 이미지 중심의 기획 배너, 배너 바로 아래 카테고리 탐색, 목적별 상품 묶음을 참고했다. 사진, 문구, 브랜드 요소는 복제하지 않았다.

이전에 생성한 인물·로봇 일러스트는 사용하지 않는다. 이번 배너는 기존 파랑, 버튼 라디우스, 글꼴을 사용한 코드 기반 캠페인 그래픽으로 구성했다. 실제 고객 사례나 상품 이미지로 오인할 가상 사진도 넣지 않았다.

## 검증

279개 자동 테스트, Next 프로덕션 빌드와 타입 검사, 프로덕션 의존성 audit 통과. 격리 DB의 HTTP 검증에 비회원·체험단·관리자 단독 세션의 가격 API 차단과 페이지 HTML 검사, 광고주 접근 허용을 추가했다. 실제 브라우저에서 390px 모바일과 데스크톱, 공개 안내에서 로그인 복귀 경로, 광고주 견적 진입, 로그아웃 후 차단과 가로 넘침을 확인한다. 운영 데이터에는 테스트 캠페인을 생성하지 않는다.
