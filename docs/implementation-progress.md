## 구현 수준과 후속 항목

- 현재 완료 범위는 최초 A의 코드 구현과 키 없이 가능한 검증이다. 전체 제품의 모든 미래 phase 완료를 뜻하지 않는다.
- 엑셀은 내용 미리보기·자료 메모 반영을 제공한다. 실제 고객 양식을 확보한 뒤 전용 컬럼 자동 매핑을 확정한다.
- 영상 기본 출력은 무음이다. 자막/음악/로고의 정교한 타임라인 편집과 음악 자산 관리 UI는 후속 보완 항목이다.
- API 비용은 입력한 예산 추정치를 예약하고, 사용량을 기록하며 청구액을 수동 확정한다. 공급사 결제의 하드 제한 또는 자동 청구 동기화가 아니다.
- 초기 단일 서버 저장소이며 배포/도메인 연결은 수행하지 않았다. 운영용 호스팅 선택 시 영속 디스크 또는 DB/객체 저장소를 결정한다.
- 게시자 포털(Phase 2), SNS 승인 후 게시(Phase 3), 데이터 축적 후 제한적 자동 운영(Phase 4)은 후속 범위로 유지.
