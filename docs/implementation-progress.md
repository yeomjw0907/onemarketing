# 개발·검증 기록

## 실행 기준

- 현재 개발: 최초 승인한 A 범위(Phase 1A~1C). 게시자 포털과 SNS 게시는 후속 단계.
- 화면 방향: 간결한 토스 느낌의 자체 PC 컴포넌트. 브랜드·독점 자산 복제 없음.
- 초기 저장 방식 변경: 단일 서버 SQLite WAL + 비공개 로컬 파일. 다중 서버/서버리스 배포 전 PostgreSQL·객체 저장소 전환 필요.
- 관리자: 환경변수의 scrypt 해시와 서버 저장 세션 사용. 실제 비밀번호·키는 Git 제외.

## Phase 1A

운영자 로그인, 고객·제품, 상품·단가, 계약 스냅샷, 월별 슬롯, 프로젝트·기획 수동 관리, 게시/지급 기록, 비용, 대시보드.

검증 결과와 commit은 검증 완료 후 기록.

## Phase 1B / Phase 1C

API adapter·영속 작업 worker·파일 보관·엑셀 읽기·승인본 ZIP·전달 버전 검증을 이어서 구현.

실 API 검증은 사용자가 .env.local에 설정하는 키로 수행. 미설정 상태를 가짜 생성 성공으로 대체하지 않는다.

Phase 1A 검증: TypeScript 통과, 도메인 테스트 2개 통과, production build 통과, 실제 브라우저에서 첫 관리자 로그인·대시보드 확인. 의존성 audit: 0 vulnerabilities. API 제작/파일/전달 버튼은 다음 1B·1C에서 연결한다.
