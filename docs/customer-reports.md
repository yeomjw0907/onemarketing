# 고객 자료 접수와 보고

## 고객 작성 양식 v2

자료실과 프로젝트 자료 탭에서 받는 고객 작성 엑셀은 참고 파일의 4번째 시트인 ‘제품 맥락 & 레퍼런스’를 기준으로 한다. 작성안내, 제품맥락, 참고자료의 3개 시트이며 브랜드·슬로건·위치·판매 채널, 제품명·구성·가격·행사 기간·USP·특징·타깃·보관법·키워드·금지 표현, 광고 표시·구매 링크·사진 순서·해시태그·사용 권한·고객 확인일을 작성한다. 행정 정보는 기존 고객 등록/파일 보관 기능에서 별도로 받는다. 기존 v1 작성본도 업로드·내용 추출이 가능하다.

## 고객 보고 링크

고객·제품 → 고객 상세 → 고객 보고 URL에서 유효 기간(30/90/180/365일)을 선택해 발급한다. 주소는 발급 직후 복사해 전달한다. 원문은 DB에 보관하지 않고 SHA-256 해시만 저장하므로 주소를 잃으면 기존 링크를 폐기하고 새로 발급한다. 발급 이력에서 개별 링크를 즉시 폐기할 수 있다. 한 고객의 전체 프로젝트가 포함되고 새 프로젝트도 같은 주소에 반영된다.

링크를 아는 고객은 관리자 로그인 없이 /reports/{token}에서 볼 수 있다. 보고에는 고객 표시명, 캠페인명·상태·마감, 블로그/클립 게시 확인 수량, 익명 참여자 번호, 콘텐츠명, 등록된 게시 링크, 운영자 확인일만 표시한다. 보수·AI 비용·마진·연락처·사업자번호·원고·고객 자료·내부 메모는 전달하지 않는다. 게시일 기록이 없으므로 실제 발행일로 추정하지 않고 확인일로 명시한다.

상단 엑셀 다운로드는 같은 공개 데이터로 보고요약·블로그게시·클립게시 시트를 생성한다. 모든 유효 프로젝트가 운영 완료이면 완료 보고로 표시하고, 진행 중 프로젝트가 있으면 진행 보고로 표시한다. 다운로드할 때마다 현재 상태를 반영하므로 완료 시 받은 엑셀을 최종본으로 보관한다. 정산 완료 여부와 고객의 캠페인 운영 완료는 별개다.

이 주소는 링크 소지자를 위한 열람 권한이므로 고객에게만 전달한다. 만료·폐기 시 화면과 다운로드 모두 차단하며 검색 색인과 외부 링크로의 referrer 전달을 차단한다. 별도 환경변수·테이블 마이그레이션은 필요 없으며 report_links 레코드 종류를 사용한다. APP_URL을 기준으로 공유 주소를 만든다. 자동 고객 메시지 발송은 하지 않는다.
