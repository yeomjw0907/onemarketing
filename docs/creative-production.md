# 클립 제작·시나리오·실행 흐름

관리자 **프로젝트 → 생성 브리핑**에서 사용한다. 이 화면의 상태는 작업 큐·현재 자산·브리핑·최종 승인 상태를 읽는다. 역할별 별도 에이전트를 실행하는 화면이나 자동화 편집기는 아니다. PC에서는 연결된 단계로, 모바일에서는 세로 순서로 표시한다. 실제 실행 오류의 상세 내용은 아래 실행 로그에서 확인한다.

## 계약 수량과 시나리오

클립별로 기존형 또는 시나리오형을 선택한다. 시나리오 후보 3개는 선택지이며 계약 작업을 추가하지 않는다. 수정·반려해도 클립 수량은 그대로다. 승인·전달한 작업은 기존 수정 요청 절차를 거쳐야 바꿀 수 있다.

시나리오형에서 요청을 작성하고 **시나리오 3개 제안**을 누르면 텍스트 모델 비용이 발생한다. 후보마다 타깃·줄거리·선정 이유·장면 시간·자막·필요 자료·CTA·위험 요소를 검토한다. 한 후보를 승인하거나 사유를 입력해 전체 후보 묶음을 수정 요청·반려한다. 다시 제안하면 이전 검토 사유를 참고한다. 기존 승인안은 새 승인안이 확정될 때까지 유지한다.

승인한 시나리오는 작업에 연결되어 원고 생성과 이미지·영상 브리핑의 입력에 포함된다. 시나리오 승인으로 영상 생성은 시작하지 않는다. 영상은 기존대로 별도 브리핑 승인 및 생성 버튼이 필요하다. 제품 정보·기획이 달라지면 새 시나리오 승인이 필요하다. 제작 방향 변경 전 원고·영상은 새 방향의 승인본으로 승인할 수 없다.

실제 촬영이 필요한 장면을 AI 생성으로 자동 대체하지 않는다. 해당 시나리오는 실제 자료로 편집한 완성 영상을 등록하거나, 촬영이 필요 없는 방향으로 다시 제안·승인해야 한다. 다중 장면의 인물·제품 일치와 사실성은 운영자 검수가 필요하다.

## 기존형 고도화

- 기준 사진을 직접 선택한다. 다른 작업·프로젝트의 사진은 기준으로 지정할 수 없다.
- 영상에 전달할 실제 720×1280 시작 프레임을 확인한다. EXIF 회전 보정과 원본 비율 유지, 흰 여백을 포함한다.
- 기존형 AI 영상은 한 번에 연속된 한 장면으로 승인한다. 제품 고정과 작은 단일 카메라 이동을 기본으로 하고 사진에 없는 단면·뒷면·공정 등을 만들지 않는다.
- 브리핑의 도입·특징·CTA 문구는 후편집으로 합성한다. 유료 광고 표시도 합성한다. 변경한 문구는 저장한 뒤 다시 승인한다. 과거 브리핑에서 후편집 문구가 없는 결과는 소급 변경하지 않는다.
- 공통 클립 규격: 720×1280. 상단 고정 제목은 영상 전체에 노출한다. 검은 상·하단 띠를 추가하지 않고 흰색 제목과 연노랑 자막에 검은 외곽선을 합성한다. 광고 표시는 상단 제목 위, 선택 설명 자막과 CTA는 영상 내부 하단 안전 영역에 표시한다. 설명·CTA가 비어 있으면 해당 자막을 생성하지 않는다. 제목이 없으면 짧은 기존 도입 문구 또는 제품·작업 이름을 사용한다. 새로 제작하는 사진형·혼합형·생성형에 같은 규격을 적용하며 이미 저장된 완성본은 소급 변경하지 않는다.
- 사진형은 검수 화면의 이미지 순서로 편집하고 미세 확대를 적용한다. 첫·마지막 사진의 노출 시간을 조금 더 배분한다. 사진형도 영상 브리핑을 승인한 후 사진 편집을 실행할 수 있으며 fal 영상 생성은 호출하지 않는다.
- 완성 후 사용한 브리핑에서 **원본·완성본 비교 검수**를 연다. 원본 사진·영상 재생·시작/중간/끝 프레임을 확인한다. 프레임은 서버에서 추출하며 별도 AI 생성 비용이 없다. 자동 품질 통과 판정은 아니며 최종 결과물 승인은 운영자가 한다.

## 검증

시나리오 공급사 요청은 테스트에서 모의 응답으로 검증한다. 승인·반려 사유·교차 작업 접근·오래된 정보·수량 보존·실제 상태 계산·시작 프레임 처리를 검사한다. 한글 광고 표시·CTA 후편집은 실제 FFmpeg 출력 프레임으로 검사한다. 새 역할별 유료 영상 생성 품질은 운영자가 캠페인 자료로 별도 검수한다.
