# 광고주 가입과 고객 계정 발급

- 광고주는 이메일 또는 카카오로 가입합니다. 카카오 최초 인증 후 담당자 이름·이메일·전화번호, 업체명·브랜드·업종·사업자 유형·사업자등록번호·주소/지역·제품/서비스 소개를 입력합니다. 홈페이지는 선택이며 창업 준비 중이면 사업자등록번호는 생략할 수 있습니다.
- 가입 시 관리자 고객 레코드를 생성하고 광고주 계정의 customer_id에 연결합니다. 고객 상세에서 정보 조회·수정이 가능합니다. 기존 광고주의 고객 연결은 변경하지 않습니다.
- 수동 고객은 먼저 고객을 저장한 뒤 고객 상세의 ‘광고주 로그인 계정’에서 이메일 아이디·초기 비밀번호·담당자·전화번호를 입력해 계정을 발급합니다. 이메일 또는 고객에 이미 계정이 있으면 중복 발급을 거절합니다. 비밀번호는 해시로 저장하며 다시 표시하지 않습니다. 관리자가 고객에게 직접 전달합니다.
- 수동 발급/기존 이메일 계정은 카카오 인증 후 ‘기존 계정에 카카오 연결’을 선택하고 기존 이메일·비밀번호로 본인 확인하면 연결됩니다. 이메일 일치만으로 자동 연결하지 않습니다.
- 카카오와 체험단은 인증 목적 및 계정 연결을 구분합니다. 카카오 연결 해제 webhook은 광고주 로그인 연결과 발급된 세션도 해제합니다.

## 환경 설정

기존 체험단 카카오 앱과 같은 callback `/api/auth/kakao/callback`을 사용하므로 새 redirect URI는 필요하지 않습니다. `KAKAO_LOGIN_ENABLED=true`, `KAKAO_CLIENT_ID`, `KAKAO_CLIENT_SECRET`, `APP_URL`이 설정되어야 버튼이 표시됩니다. 운영 Vercel에는 기존 카카오 설정이 등록되어 있습니다. 로컬에는 별도 설정이 필요합니다. 카카오 provider 응답은 자동 테스트에서 mock하며 실제 카카오 사용자 승인은 수동 확인 대상입니다.

별도 DB migration은 필요 없습니다. 기존 advertiser_accounts, advertiser_sessions, portal_links 및 customers JSON 필드를 사용합니다.
