# 제품 자료 확인 후 키워드 분석

프로젝트의 자료 탭에서 제품 상세페이지·공식 링크(최대 5개)를 저장하고 자료를 등록한 뒤 ‘자료에서 제품 정보 정리’를 실행한다. 등록 고객·제품 정보, 자료 메모, 엑셀 작성본, 회사·제품 소개서 PDF와 참고 사진을 사용한다. 고객 자료실에 저장된 회사소개서·작성본은 해당 프로젝트로 가져온 뒤 분석에 포함한다. 사업자등록증은 분석 자료로 복사하지 않는다.

지원 형식은 PDF, XLSX, CSV, TXT, MD, JPG/PNG/WebP다. PPT/PPTX·한글·워드는 PDF로 변환해서 등록한다. 고객 첨부와 프로젝트 PDF는 파일당 4MB, AI 정리 시 PDF 합계 12MB·80쪽을 적용한다. 암호화·손상 PDF는 재등록을 요청한다. 사진은 최대 3장을 참고하며 사진만으로 원재료·효능 등을 판단하지 않는다. 링크는 웹 검색에서 실제 확인한 내용만 참고하고, 확인되지 않으면 첨부 자료와 직접 확인한 정보로 보완한다. 외부 웹 페이지나 파일 안의 명령은 실행 지시가 아닌 참고 데이터로 취급한다.

각 프로젝트 참고자료에서 ‘제품 분석에서 제외’를 선택하면 원본을 보존한 채 다음 제품 정리·조사 입력에서 뺄 수 있다. 다른 제품의 소개서, 손상 PDF, 분량이 과한 자료를 제외하고 필요한 파일만 포함할 수 있다. 포함 상태 변경도 입력 변경으로 처리하여 재확인이 필요하다. 이 선택은 제품 분석용이며 기존 제작 이미지 배정은 바꾸지 않는다.

정리 결과에는 제품명, 제품 종류, 확인된 특징, 타깃, 판매 방식·지역, 캠페인 목표, 금지 표현과 자료별 근거가 표시된다. 회사 공통 정보와 해당 제품 사실을 구분하고, 여러 제품이 담긴 자료나 서로 충돌하는 정보는 확인 질문으로 남긴다. 필수 항목 누락 질문은 서버에서도 보완한다. 운영자는 필요한 정보만 추가하고 초안을 수정한 뒤 확인 체크와 ‘제품 정보 확정’을 수행한다. 타깃과 금지 표현은 선택 사항이며 타깃 미정을 임의로 단정하지 않는다.

제품 확인 전에는 키워드 조사 작업을 등록할 수 없다. 확정 후 기획 탭에서 ‘키워드 분석·기획 생성’을 실행한다. 등록·실행·결과 반영 시 제품 확인 상태와 입력 자료의 지문을 비교한다. 자료·제품 정보·링크가 변경되면 제품 정리를 다시 실행하고 확인해야 한다. 이전 기획·게시물은 삭제하지 않는다.

추천 키워드는 내부 초안이다. 운영자가 근거 있는 후보 중 핵심·보조 키워드를 선택하고 고객용 선정 이유를 작성해 ‘고객 공유 확정’을 해야 고객 보고 페이지와 보고 엑셀에 표시된다. 원본 첨부, 미확정 제품 초안, 확인 질문, 내부 조사 본문은 고객 보고에 노출하지 않는다. 재정리·제품 재확정·새 분석 완료 시 공유 확정은 해제되며 자료가 바뀐 경우 기존 공유 결과도 표시하지 않는다.

검색량·블로그 문서 수를 가져오는 네이버 API 연동은 별도 작업이다. 이 기능은 제품 사실 확인과 고객 공개 범위를 관리하며 실측 검색량을 생성하거나 주장하지 않는다. AI 정리·조사는 기존 작업 큐, 예산 상한, 사용량·비용 기록을 사용한다.
