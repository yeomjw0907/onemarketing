# 공개 플랫폼 구현

기존 참여자 가입·인증·작업·추천 보상을 재사용하며 운영 데이터는 삭제하지 않는다. 공개 이름은 원마케팅, 관리자는 /admin. 웹과 MCP는 공통 서버 로직을 사용한다. 20만원 패키지는 VAT 별도로 22만원. 신규 가격은 버전·주문별 스냅샷으로 저장한다. 결제는 설정된 계좌로 이체 후 관리자 확인, 환불 요청·승인·실제 송금 기록을 구분한다. 카드 결제를 흉내내지 않는다.

## Phase 1 공개 구조
공개 메인·헤더·푸터, 역할별 가입·로그인, 관리자 분리, AI 소개·정책. 타입 검사·빌드 후 커밋·푸시.

## Phase 2 상거래
서버 상품 정책·장바구니·중복 구성 검사·주문 스냅샷·입금 확인·격리 DB 테스트 후 커밋·푸시.

## Phase 3 운영
광고주 지원자·검수·환불, 관리자 결제·대행·환불, 참여자 지원·수락·제출 연결. 권한·동시성 검증 후 커밋·푸시.

## Phase 4 AI와 통합 검증
광고주별 AI 연결·해제·권한 범위·공통 주문 처리. 반응형 브라우저·권한 회귀·빌드 후 커밋·푸시.

## 완료 기록

- Phase 1: `53a62b3` 공개 페이지·역할별 진입. 타입 검사·빌드 통과 후 푸시.
- Phase 2: `e12a3e6` 서버 가격·장바구니·주문·입금 처리. 격리 DB 테스트·타입 검사·빌드 통과 후 푸시.
- Phase 3: `f700590` 광고주·관리자·체험단 업무 화면과 제출·검수·보수·환불. 관련 12개 테스트·타입 검사·빌드 통과 후 푸시.
- Phase 4: 광고주 MCP·OAuth·키 연결/해제·Skill, 기존 AI 제작 파일 전달, 일정/문의, 만료/Cron 연결. 최종 전체 271개 테스트·타입 검사·운영 빌드·격리 HTTP MCP/OAuth 통합 검증 통과. 브라우저에서 가입→장바구니 복원→주문→마이페이지를 확인했고 390px 모바일 가로 넘침은 없었다.

운영 적용·설정·외부 계정 검증 범위는 [운영 안내](platform-operations.md)를 따른다. 개발 브랜치 푸시를 공개 배포 완료로 간주하지 않는다.
