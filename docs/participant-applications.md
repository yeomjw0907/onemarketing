# 체험단 참여 신청

- 공개 신청 주소: `/participants/apply` (로그인 불필요)
- 보수·참여 조건을 끝까지 읽은 후 ‘동의합니다’ 버튼으로 신청서를 연다.
- 첫 안내와 참여 조건에 원마케팅의 콘텐츠 제작·전달 및 참여자의 업로드·링크 제출 역할을 명시한다. 블로그 규모·기한 준수·게시 유지 등 이행 내역에 따른 추가 보수는 참여 전에 개별 협의하며 자동 인상을 약속하지 않는다.
- 신청 항목은 이름, 자동 하이픈 휴대전화, 추천 주소를 제공하는 단일 이메일 입력, 활동 지역, 활동 계정, 정산 방식이다. 계좌 송금을 선택한 경우 은행과 계좌번호를 필수로 받는다.
- 활동 계정에서 네이버 클립은 별도로 선택하지 않고 네이버 블로그로 통합한다. 클립 업로드 보수 안내는 유지한다.
- 채널별 입력 제목·예시·오류 안내를 제공한다. 인스타그램은 아이디·@아이디·프로필 URL, 유튜브는 @핸들·채널 URL을 받으며 서버에서 표준 URL로 변환해 저장하고 중복 검사한다. 페이스북·링크드인은 해당 플랫폼의 프로필·페이지 주소를 받는다.
- 모든 입력은 공통 스타일과 항목별 오류 안내를 사용한다. 정산 방식은 체크가 있는 선택 버튼이며, 은행은 검색·선택 또는 직접 입력할 수 있다.
- 제출 시 ‘접수하시겠습니까?’ 팝업에서 확인해야 접수 요청을 전송한다. 완료 후 개별 연락 안내와 문의 연락처를 표시한다.
- 카카오페이는 신청 휴대전화로 개별 정산을 안내하며 결제 API와 연결된 자동 송금은 아니다. 정산 정보는 승인된 참여자 프로필에도 보존된다.
- 관리자: 체험단 관리 → 체험단 참여 신청 → 신규 → 검토·수정
- 수정 내용 저장은 접수 정보만 변경한다. 승인 버튼은 현재 수정 내용을 반영해 기존 참여자를 생성하고 해당 프로필을 연다.
- 승인 완료·반려 탭에서 처리 결과를 조회한다. 반려 신청은 다시 수정·승인할 수 있으며 수정 저장만 하면 반려 상태를 유지한다. 승인된 참여자는 기존 프로필 수정 기능을 사용한다.
- 신청 목록은 우측 상단의 공통 새로고침 버튼으로 갱신한다. 신청 목록·검토 화면·참여자 프로필에서 전화번호와 이메일을 복사할 수 있다.
- 승인과 접수 상태 변경은 하나의 트랜잭션으로 처리한다. 동시 승인은 동일한 참여자 ID를 반환하고, 중복 계정이나 수정 충돌은 등록 전에 차단한다.
- 신청 API의 조회·검토는 기존 관리자 세션이 필요하다. 공개 접수에는 개인정보 동의, 웹 계정 주소 검사, 전화번호별 일일 접수 제한, 숨김 스팸 필드가 적용된다.

## 데이터베이스

`20261015010000_participant_applications.sql`을 배포 대상 DB에 적용해야 한다 (`npm run db:migrate`). 신청 정보는 별도 `participant_applications` 테이블에 저장하며 기존 레코드 종류와 정산 구조를 변경하지 않는다.

## 운영

신청 페이지의 개인정보 안내는 신청 정보 접수 후 1년, 승인된 프로필은 협업 종료 후 1년 보관을 기준으로 작성했다. 실제 운영에 맞게 안내를 유지하고 보관기간이 지난 정보는 담당자가 삭제한다. 자동 삭제 기능과 신청자 알림 발송은 포함하지 않는다.

검증: 격리 DB 테스트, 프로덕션 빌드, 모바일 390px 폼 작성·접수 및 관리자 수정 후 승인·프로필 등록을 확인했다.


## 신규 신청 자동 승인 및 사후 검수

새 신청은 필수 정보·동의·정산 방식·중복 검사를 통과하면 즉시 참여자로 등록되며 카카오 로그인 연결도 완료된다. 활동 계정도 자동 승인하며 운영자는 신청 목록의 `자동 승인 · 미검수`에서 사후 검수한다. 기존 승인 대기 신청은 자동 전환하지 않는다.

추천 코드가 적용된 신규 신청에는 1회 2,000원 보상을 `pending_review`로 기록한다. 개별 또는 일괄 `검수 완료 · 보상 확정` 시 `available`로 전환되며, 실제 송금 후 기존 추천료 정산에서 지급 완료를 기록한다. 검수 전 보상은 정산 대상에 포함되지 않는다. `보상 제외`는 신규 보상만 취소하며 회원 이용은 유지한다. 부적합 회원은 참여자 수정·삭제에서 처리한다.

회원 삭제 시 해당 회원이 발생시킨 미지급 신규 보상과 해당 회원에게 지급할 미지급 신규 보상을 취소한다. 삭제 후 복구해도 취소 보상은 자동 복원하지 않는다. 삭제·정산 기록은 보존하며 등록된 활동 계정·전화번호로 재가입하여 중복 보상을 받는 것을 차단한다. 이미 지급한 보상과 기존 캠페인 추천료(단독 500원·묶음 1,200원)는 변경하지 않는다.
