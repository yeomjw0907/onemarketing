# 운영자·참여자·고객 화면 안내

## 프로젝트에서 다음 할 일 확인

프로젝트 상단의 '지금 할 일'은 제품 정보 확인, 기획, 제작, 결과물 검수, 참여 제안, 자료 전달, 게시물 검수, 원고료 확인을 현재 상태에 맞춰 표시한다. 버튼을 누르면 해당 프로젝트의 관련 탭이나 캠페인 운영 화면으로 이동한다. 모집·검수 화면의 프로젝트와 탭은 URL에 보관해 새로고침에도 유지한다.

제안 진행 중인 슬롯은 중복 모집으로 표시하지 않는다. 묶음 자료는 모든 작업이 승인된 경우만 전달 항목에 나타난다. 제출 후 3일 전에는 검수 대기로 안내한다. 전체 지급은 슬롯·배정으로, 부분 정산은 검수·유지 화면으로 연결한다. 실행 중인 생성은 중복 제작 안내에서 제외한다. 보류·마감 프로젝트는 새 제작 안내를 숨기지만 게시 유지 이상은 표시한다. 안내는 상태를 바꾸거나 메시지·지급을 실행하지 않는다.

## 생성 브리핑

장면 요약, 확인할 사항, 제목 미리보기와 다음 행동을 먼저 보여준다. 장면 수정, 원본 프롬프트 수정, 제목 설정, 최종 프롬프트는 펼쳐서 볼 수 있다. 저장·승인·생성 버튼은 유지하고 현재 필요한 버튼 하나를 강조한다. 수정하면 기존 승인 해제와 재승인 절차가 유지된다. 모바일에서는 프로젝트 제목과 작업 제목이 버튼·배지에 밀리지 않게 배치한다.

## 참여자 화면

새 제안이 없고 배정 작업이 있으면 게시 작업을 먼저 연다. 자료 준비, 게시, 수정 요청, 제출 완료, 검수 통과, 지급 완료, 게시물 복구를 구분해 안내한다. 수정 내용과 기한은 작업 상단에 표시한다. 게시 전에는 자료와 제출 입력을 펼치고, 제출 후에는 자료 다시 보기와 링크 변경을 접어 불필요한 재제출을 줄인다. 기존 자료 저장·원고 복사·앱 열기와 제출 기능은 유지한다.

## 고객 보고

한국 시간 월요일~일요일을 기준으로 게시 마감 예정 건수, 그 작업의 링크 접수·게시 확인 건수, 예정일이 지난 미접수 건수를 표시한다. 일정이 없는 작업은 조율 중으로 안내한다. 접수와 검수를 구분하고 근거 없이 정상 진행·성과·추가 자료 불필요 등을 단정하지 않는다. 같은 집계는 보고 엑셀에도 포함한다. 내부 프롬프트·비용·개인정보를 추가 공개하지 않는다.

## 화면 문구 기준

[AI 말투 교정법 참고 글](https://www.digitalmarketer.co.kr/insights/ai-writing-tone-editing)을 참고해 표현을 줄이되 사실과 조건을 남긴다. 주체와 행동을 구체적으로 쓰고, 중복 안내와 근거 없는 효과·속도·완료 약속은 피한다. 게시 유지 90일, 검수 대기 3일, 승인·지급의 구분, 실제 생성 비용과 재승인 조건은 문구를 줄여도 보존한다. 필요한 버튼 이름과 실행 안내까지 기계적으로 지우지는 않는다.
