# 클립 연구소 추가 1,000개 분석과 피자설기 제작 결과

2026년 11월 3일에 추가 영상 1,000개의 AI 관찰을 저장하고 구조를 검증했다. 서로 다른 URL 1,000개이며 기존 30개 시험과의 중복은 0개다. 대표 구간 관찰 3,061개와 편집 가설 1,000개를 확보했다. 피자설기 가상 광고 예시 3편도 실제 MP4로 제작했다.

## 제작에 적용한 개선

기존 Gemini와 fal을 유지하고, 짧은 움직임을 생성하는 단계와 문구·음성을 편집하는 단계를 분리했다. 새 생성 모델을 계속 추가하기보다 장면의 시작 상태, 종료 상태, 연결할 위치·방향·광원을 먼저 정하도록 바꿨다.

운영 코드의 영상 브리핑과 검수 화면에 시작·끝 상태 및 다음 장면과 맞출 조건을 추가했다. 승인한 조건은 실제 생성 프롬프트에 포함된다. 기존 브리핑은 그대로 사용할 수 있고 이미지 브리핑에는 영상용 필드를 표시하지 않는다.

로컬 편집기는 JSON 계획을 HyperFrames의 장면·영상·문구·음성 트랙으로 컴파일한다. 연구소에서는 원본 링크, 관찰, 조건별 편집 가설을 검색하고 조회수로 후보를 좁힐 수 있다. 근거 영상을 연결하고 검토 상태를 보존한다. 자동 규칙 검색은 기본적으로 원본 대조 기록이 있는 자료만 사용하며, 가상 제작 실험에서는 검토 전 후보를 명시적으로 허용했다.

## 피자설기 예시 3편

세 편 모두 12초, 1080×1920, 30fps, H.264 영상과 AAC 스테레오 음성이다.

1. 질문으로 시작: “피자일까요? → 설기일까요? → 피자설기.” 근접 장면에서 전체와 제품 소개로 이어진다.
2. 세부를 따라가기: “네모난 설기 위, → 조금 더 가까이 → 작은 디테일.” 전체에서 세부로 화면 크기를 바꾼다.
3. 식탁 분위기: “오늘의 간식, → 새로운 모양으로. → 피자설기.” 여백을 둔 화면 안에서 제품을 보여준다.

서비스의 이전 생성 기록에서 확보한 가상 제품 이미지 3장을 사용했다. Seedance로 5초짜리 움직이는 영상 3개를 새로 생성하고, 각 편에서 4초씩 골라 다른 순서로 연결했다. 서로 다른 원본 영상 9개를 생성한 것은 아니다. MiniMax 한국어 더빙 3개와 Stable Audio 음악 1개를 별도 트랙으로 사용했다. 화면 문구는 장면 제목이며 단어 단위 더빙 자막은 아니다.

확인되지 않은 재료·맛·가격·효능을 문구에 넣지 않았다. 실제 제품 광고를 납품하거나 게시한 것이 아니라 가상 제작 예시다. 음식의 손동작·절단·증기·치즈 늘어남을 추가하지 않고 카메라의 작은 움직임을 중심으로 생성했다.

초기 관찰에서 선택한 연출을 제작한 뒤, 전체 관찰 카탈로그의 조건 검색으로 각 편의 구성 근거를 연결했다. 연결한 가설과 원본 링크는 각 편집 프로젝트의 `EVIDENCE.md`에 있다. 아직 광고 효과가 입증된 제작 규칙은 아니다.

## 분석 범위와 표본

공개 Shorts 탭 44곳에서 후보 1,800개를 수집했다. 성공한 1,000개는 음식 411개, 제품 200개, 광고 123개, 뷰티 100개, 생활 85개, 커피 81개다. 분야는 수집 채널을 기준으로 정한 임시 분류다. 표시 조회수 100만 회 이상은 285개, 1,000만 회 이상은 81개다. 게시 후 경과 시간·유료 노출은 보정하지 않았고 좋아요·댓글·유지율·구매 전환은 측정하지 않았다.

직접 API 요청 모델 `gemini-3.1-flash-lite`로 669개를 분석했다. 앞 30초와 1fps를 명시한 영상 입력을 사용했다. 장시간 대기가 반환된 뒤에는 fal/OpenRouter의 `google/gemini-3.5-flash-lite`로 331개를 분석했다. 이 경로는 공개 URL과 첫 30초 관찰 지시를 사용했지만 실제 입력 범위와 샘플링은 공급사 기본값이다. 두 경로의 조건은 개별 기록에 구분했다.

관찰 문구를 검색하면 접근·확대 관련 표현은 654개, 옆 이동은 173개, 전체·세부는 94개, 위치·방향 연결은 573개, 형태·배치 유지는 840개 기록에 있다. 이는 키워드 분류 결과이며 장면의 실제 사용 빈도나 성공 원인을 증명하지 않는다. 특히 연결 조건은 프롬프트에서 요구한 필드이므로 빈도를 독립적인 성과 지표로 해석하면 안 된다.

1,000개 모두 화면 접근 여부, 한국어 응답, 시간 범위·중첩, 필수 관찰 필드, 원본 ID와 근거 구간 참조를 검사했다. 원본 대조 완료로 승격한 자료는 0개다. AI 관찰의 정확도와 효과를 전수 검증했다는 뜻이 아니다. 모델 가중치 재학습이나 미세 조정도 수행하지 않았다.

## 비용과 검증

직접 Gemini API의 사용량이 확인된 요청을 유료 표준 단가로 환산하면 약 1.1646달러다. 사용한 키의 무료 한도와 실제 청구서는 별개다. fal 영상 분석 응답에서 보고된 비용은 약 1.3056달러이며 청구서와 대조하지 않았다. 사용량이 없는 거절·불확실 요청은 확정 비용으로 계산하지 않았다.

이번 예시의 생성 영상은 720p 총 15초다. fal 공식 초당 근사 단가로는 약 7.10달러, 음악 1개는 0.20달러, 음성은 약 0.01달러 수준이다. 이 역시 실제 청구액이 아니다. 예전 이미지 3장은 재사용했다. vidIQ 크레딧은 사용하지 않았다.

연구소 자동 검사 25개, 기존 영상 편집과 새 프롬프트 연속성 검사 4개, TypeScript 검사와 Next.js 프로덕션 빌드를 통과했다. 예시 세 편은 HyperFrames의 구문·실행·배치·움직임·대비·오디오 검사를 통과했다. 장면과 컷 주변 프레임, 휴대폰 크기 화면을 확인했고 독립 시각 검토에서도 P0/P1 문제는 나오지 않았다.

최종 MP4 전체 디코딩과 음성 트랙을 확인했다. 더빙 문장은 별도 AI 전사로 확인했고 사람이 청취하지는 않았다. 오디오를 보정한 뒤 세 편의 통합 음량은 약 −17.1~−17.4 LUFS, true peak는 −1.25~−1.49 dBTP다. 보정 전후 영상 스트림 해시가 같아 영상은 재인코딩하지 않았음을 확인했다.

## 남은 개선과 운영 범위

현재 예시는 서로 다른 기준 이미지에서 생성했으므로 장면 사이 제품 크기와 각도가 완전히 일치하지 않는다. 장면당 4초의 균등한 리듬도 비교가 필요하다. 다음 실험에서는 같은 카메라 높이의 기준 프레임, 끝 프레임을 다음 장면의 시작으로 쓰는 방식, 첫 장면 2초와 4초의 구성을 비교하는 것이 적합하다.

운영 서비스에는 브리핑 조건과 검수 필드를 연결했다. 다중 클립 생성·음성·Chrome 렌더 전체를 고객용 자동 제작 흐름에 배포한 것은 아니다. 로컬 편집 프로젝트와 CLI에서 검증했다. 운영 큐 연결에는 권한, 작업 lease, 비용 예약과 재시작 복구가 추가로 필요하다.

실행 방법과 공식 근거는 [확장 구현 문서](clip-lab-production.md), 재사용 가능한 관찰 자산은 [카탈로그 안내](../data/clip-lab/README.md)를 참고한다.
