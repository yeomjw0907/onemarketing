# AI 실행 상태와 진단 로그

프로젝트 화면의 모든 탭 아래에 실시간 실행 상태와 로그를 표시한다. 관리자 인증이 필요한 /api/job-logs에서 프로젝트/작업 범위 최근 500개를 4초마다 조회한다. 작업 필터, 자동 스크롤, TXT 다운로드를 지원한다. 브라우저 탭이 숨겨지면 조회를 쉬고 요청이 끝난 뒤 다음 조회를 예약한다.

대기열 등록, 실행 시작/회차, 조사·분석·기획·원고 단계, 공급사 HTTP 요청/응답 코드·경과 시간, 모델·요청 ID, fal 큐 상태 변화, Supabase 업로드, 완료·오류·서버리스 이어받기를 기록한다. 공급사 호출 성공과 전체 작업 성공은 구분한다. 공급사가 제공하지 않는 퍼센트 진행률은 만들지 않는다.

로그는 records의 job_logs 종류에 추가 저장하고 일반 /api/data 뷰에서는 제외한다. 별도 마이그레이션은 필요 없다. API 키, DB URL, 서명된 파일 URL, 프롬프트/응답 원문은 저장하지 않는다. 로그 저장 실패는 유료 공급사 호출을 재시도시키지 않는다. 기존 요청 ID·체크포인트가 있는 작업만 기존 요청 재조회로 이어갈 수 있다. 모호한 실패에는 자동 새 생성 요청을 보내지 않는다.

고객 보고 URL은 이 로그를 제공하지 않는다. TXT에는 진단용 프로젝트/작업 ID와 요청 ID가 포함되므로 내부에서 보관한다. 비용 화면의 잠정 금액은 실제 청구액을 뜻하지 않는다.

HTTP 오류의 응답 원문은 저장하지 않고 알려진 잔액 소진·인증 실패·권한 부족 사유만 분류해 표시한다. 실제 예시 실행에서 발견한 사진 미전달을 보완해 Claude 분석/기획/원고 요청에는 고객 참고 사진을 최대 3장, 긴 변 1280px 이내 JPEG로 전달한다. 사진 속 글자는 명령이 아닌 참고 데이터로 취급하고 사진만으로 성분·효능·맛을 단정하지 않도록 한다. 사진 데이터 자체는 진단 로그에 포함하지 않는다.

## AI 비용 대조와 집계

대시보드와 프로젝트의 비용·기록 탭에서 이미지·영상·원고·조사·기획·생성 브리핑별 금액과 개별 API 요청, 프로젝트별, 일별, 월별 합계를 확인합니다. 프로젝트·공급사·시작일·종료일 필터가 상세 집계에 적용됩니다. 오늘·이번 달·누적 카드에는 선택한 프로젝트·공급사의 해당 기간 실제 USD가 표시됩니다.

fal 실제 청구 확인 버튼은 최근 90일 이내 플랫폼 요청 ID만 Billing Events API로 조회합니다. 페이지를 끝까지 조회한 결과를 저장하며, 실제 청구가 없는 응답은 무료로 간주하지 않고 미확인 상태로 남깁니다. 같은 청구를 다시 조회해도 누적 가산하지 않습니다. 90일 이전 금액은 저장된 청구 내역을 유지합니다. 작업 완료 직후에는 공급사 청구 반영이 지연될 수 있으므로 나중에 재조회합니다. 이 플랫폼 밖에서 생성한 fal 요청은 집계하지 않습니다.

실제 USD 청구액이 있으면 해당 요청의 원화 잠정 금액을 AI 상세 집계에서 제외합니다. 원화 확정·잠정 비용과 USD는 환율 없이 더하지 않습니다. 기존 예산·원가·정산의 원화 금액은 별도이며 원화로 확정하기 전에는 실제 USD 원가를 환산한 값이 아닙니다.

Claude는 응답의 입력·출력·캐시 토큰과 웹 검색 횟수에 공식 단가를 적용한 추정치입니다. 출력 토큰에 포함된 thinking 토큰을 다시 더하지 않습니다. 지원하지 않는 모델·서비스 등급·사용량은 미확인으로 표시하며 0달러로 간주하지 않습니다. 새 Claude 호출에는 계산 근거·단가 기준일을 함께 저장합니다. 기존 내역은 2026-10-15 확인한 공식 단가로 추정합니다. 크레딧·할인·세금·실제 결제액을 확정하지 않습니다.

날짜는 한국 시간의 fal 청구 발생일, Claude API 응답일 또는 비용 등록일입니다. 청구 동기화 시각으로 과거 비용을 오늘에 옮기지 않습니다. 재작성·재생성도 별도 요청 비용으로 포함합니다. **예상 총사용 비용**은 확인된 USD와 사용량 추정 USD만 더한 참고 합계이며, 원화·미확인 비용은 별도 표시합니다.

### 원화 참고 환산

AI 비용 카드·개별 요청·종류별·프로젝트별·일별·월별 표에 USD와 환산원화를 함께 표시합니다. **예상 합계 · 환산원화**는 실제 USD와 사용량 추정 USD를 더한 뒤 환산한 금액입니다. 원화 수동 확정·잠정 비용은 별도이며 이 USD 환산 합계에 다시 더하지 않습니다.

ECB의 USD/KRW 일별 기준 환율을 Frankfurter v2 API로 조회하고, 적용 환율·원자료 기준일·출처를 화면에 표시합니다. API 키는 필요하지 않습니다. 확인한 환율은 서버 DB에 6시간 캐시하고 **환율 재조회**로 갱신할 수 있습니다. 주말·공휴일에는 마지막 발표일의 환율이 반환될 수 있습니다. 조회 실패 시 마지막 확인 환율과 실패 상태를 표시하며, 저장된 환율도 없으면 원화 환산을 표시하지 않고 USD를 유지합니다.

모든 조회 기간에 화면의 동일한 최신 확인 환율을 적용합니다. 거래 당시 환율이나 카드 수수료·세금이 포함된 결제액은 아닙니다. 표시를 위한 참고 환산이며 기존 비용 원장·예산·원화 정산 금액을 변경하지 않습니다. 합계는 USD 합산 후 원 단위로 반올림하므로 개별 반올림 금액의 합과 소액 차이가 날 수 있습니다.

환율 출처: https://frankfurter.dev/ (ECB provider)
