# 개선 구현 및 사용 안내

관리자 사이드바의 **캠페인 운영**에서 새 견적·일정·문서 검토·프로젝트 생성·참여 제안·웹 전달·추천 정산·알림 이력을 처리한다. 기존 계약·제작·게시·지급 화면은 유지한다.

## 기본값
- 원고료: 블로그 3,000원 / 클립 3,000원 / 묶음 7,000원. 기존 참여자별 약정액 우선.
- 직접 추천 영구 지급: 개별 500원 / 묶음 1,200원. 원고료 지급 완료 기록에 연동.
- 준비 7일 / 제안 48시간 / 자료 전달 후 제출 7일 / 수정 2일. 캠페인별 변경 가능. 수락 시 조건을 보관한다.
- 새 캠페인 검수: 제출 후 3일. 링크 교체는 새 제출로 처리. 검수 승인일부터 90일 유지 관리.

## 운영 흐름
1. 고객 및 제품 등록. 제품이 없으면 새 견적에서 브랜드·업체 홍보 선택.
2. 캠페인 운영에서 고객·총수량·기간·판매 단가·가이드 입력 후 초안 저장.
3. 자동 주차 배분 확인·수정 후 다시 저장. 견적서 PDF와 설명서 PDF를 검토하고 최종 확정.
4. 프로젝트/작업 자동 생성. 기존 제작 화면에서 자료 수집·기획·콘텐츠 제작 및 내부 승인.
5. 계정 권한은 프로필 임시 문구 등의 증빙을 운영자가 확인한 뒤 근거를 기록. 참여자 접속 링크 발급 후 직접 공유.
6. 묶음 우선 제안. 필요하면 미배정 묶음 분리. 여러 제안 일괄 등록과 참여자 일괄 수락 지원. 블로그 단독 참여자에게 남은 클립을 묶음으로 제안할 수 있다.
7. 승인본 전달 시 참여자 화면에 파일 공개, 제출 기한 확정, 알림톡 큐 생성.
8. 참여자 링크 제출 → 3일 후 운영자 검수 → 실제 송금 후 기존 정산 화면에서 완료 기록. 추천료를 함께 정산하거나 별도 합산 지급할 수 있다.
9. 부분 완료는 개별 지급 기록 후 묶음 완료 차액 정산. 미완료 작업은 기존 배정 종료 후 재모집. 부분 지급 기록 취소 지원.
10. 90일 유지 종료일과 공개 확인 기록 관리. 삭제/비공개 확인 시 복구 알림 준비.

## 접근과 발송
참여자 접속은 30일 만료 링크와 HttpOnly 쿠키를 사용한다. 재발급 시 이전 링크와 세션은 무효화한다. 링크를 가진 사람은 해당 참여자에 접근하므로 본인에게만 전달한다. 다른 참여자의 파일·연락처·계좌와 내부 원가를 참여자 API에 반환하지 않는다.

SENS는 설정·템플릿 승인·실제 수신 테스트 전까지 비활성. 업무 정보성 알림만 연결하며 문자 대체 OFF. 비친구 모집 광고는 확대 이용 자격이 확인되지 않아 발송하지 않는다. 자세한 설정은 docs/sens-setup.md 참조.

## 적용 범위와 한계
- 기존 확정 계약과 과거 단가·지급 기록은 자동 변경하지 않는다. 기존 작업은 과거 검수 규칙을 유지하고 새 견적 프로젝트에 3일/90일 정책을 적용한다.
- 기존 SNS 계정의 중복 입력/새 배정은 주소 식별로 차단한다. 플랫폼 고유 ID API 연결과 계정 소유 자동 인증은 아직 없으며 운영자가 근거를 확인한다.
- 게시물 실제 내용·공개 유지 여부의 판단은 운영자가 한다. 자동 스크래핑으로 삭제를 판정하지 않는다.
- 실제 송금은 자동 실행하지 않는다. 지급 완료 기록·추천료 원장·알림을 연결한다. 이미 지급한 추천료의 원작업이 취소되면 회수 확인 대상으로 보존한다.
- 현재 상품 제작은 네이버 블로그·클립. 인스타 등은 향후 플랫폼별 제작·검수 추가 시 활성화한다. 콘텐츠 고객 승인도 향후 확장 대상이다.
- 새 레코드 종류는 기존 JSONB records를 사용하므로 운영 DB 마이그레이션이나 과거 데이터 일괄 수정이 없다.
- 견적 원본의 서식·도장과 회사 정보를 유지한다. ExcelJS 호환을 위해 복사본 OOXML 경로/네임스페이스만 정규화했다.

## 검증
분리된 테스트 DB 스키마에서 전체 테스트, 타입 검사, Next.js 프로덕션 빌드를 수행한다. 알림 API는 모의 응답으로 서명·중복·결과·불명확 실패를 확인하며 실제 메시지를 보내지 않는다. 견적·설명 PDF는 생성 후 렌더링하여 확인한다. 로컬 격리 서버에서 관리자 견적 입력·문서 다운로드·최종 확정 및 참여자 접속 화면을 확인한다.
