# 참여자 작업부터 정산까지 점검 (2026-10-16)

## 확인한 흐름
- 격리된 workflow_qa_20261016 DB와 전용 Storage 접두어 사용. 카카오 공급자 응답만 모의 처리하고 실제 브라우저·API·비공개 파일 저장소로 확인.
- 관리자가 캠페인 운영 > 모집·배정에서 묶음 제안 등록.
- 참여자가 조건 확인 후 수락. 블로그·클립 작업 자동 배정, 자료 전달 전 파일 비노출.
- 내부 승인 전 전달 거부 확인. 원고·계약 수량 이미지·영상 내부 승인 후 자료 전달 및 materials 알림 대기열 생성.
- 참여자 화면에서 원고/가이드 확인, 실제 비공개 이미지 3장과 재생 가능한 테스트 MP4 다운로드 성공(200, 비어 있지 않은 파일).
- 다른 블로그 계정 링크 거부, 본인 블로그·클립 링크 제출 및 검수 대기 전환.
- 관리자 화면에서 제출 3일 이전 승인 거부. QA 타임스탬프만 조정해 3일 이후 검수 승인 확인.
- 묶음 두 게시물 모두 검수 완료 전 전체 지급 불가. 검수 승인 후 유지 종료 90일 기록.
- 체험단 관리 > 참여자 > 정산 이력에서 실제 송금 확인 후 합산 지급 기록하는 UI 확인. 테스트에서는 실제 송금하지 않고 격리 DB에 기록만 생성.
- 묶음 7,000원 및 개별 블로그 3,000원 지급 상태/참여자 지급 내역 확인.
- 추천료 묶음 1,200원, 개별 500원 생성. 같은 정산 요청 재전송은 같은 기록 반환하고 새 요청의 기지급 항목 재정산 거부.
- 본인 외 작업 제출 거부, 미인증 파일 다운로드 거부, 지급한 링크 변경 거부 확인.
- 알림톡 발송 활성화 또는 검수 자동 확인 재개는 하지 않음.

## 수정
- 참여자 지급 내역이 합산 정산만 표시하던 누락 수정. 직접 슬롯 지급·게시 세트 지급·부분 지급·독립 작업·과거 지급 이력 포함.
- 합산 정산/묶음 하위 작업 중복 계산 방지. 부분 3,000원 + 잔액 합산 4,000원은 합계 7,000원으로 표시.
- 부분 지급일을 별도 기록하여 잔액 지급 시 최초 지급 날짜가 덮이지 않도록 보완.
- 검수 승인 재시도 시 이전 오류 메시지 초기화, 성공 안내 추가.

## 검증
- 관련 15개 테스트 통과: participant-workflow, portal-payment-history, workflow-improvements, work-slots.
- production build/타입 검사 통과.
- 참여자 제출/지급 화면 PC 1440px, 모바일 390/360px 가로 넘침 없음.
- 실제 네이버 게시물 생성·외부 송금·카카오 메시지 발송은 실행하지 않음. 실제 게시물의 내용/공개 유지/클립 소유 여부는 관리자 검수 과정에서 확인.
- QA 객체와 스키마는 확인 완료 후 삭제.
