# 2026-10-16 개선 합의 및 구현 기준

## 확정 범위
- 정상 다계정 운영 허용. SNS 소유/관리권한 확인, 접수/등록/배정/게시물 중복 방지.
- 직접 추천 회원의 유효 활동에 영구 추천료: 블로그 500원, 클립 500원, 묶음 1,200원. 자기/순환 추천 금지. 지급 연동 적립/취소, 잔액 이월, 합산 정산, 변경 이력.
- 참여자 전용 화면: 비공개 접근, 제안 수락/거절, 계정별 가용수량, 가이드/승인 파일, 제출/수정/정산/추천 현황.
- 고객 납품은 채널별 총수량. 묶음 우선 모집, 미배정 묶음 분리, 같은 참여자 미지급 작업 합치기. 부분 완료 개별 정산, 묶음 완료 차액 지급.
- 제출 3일 후 검수, 승인일부터 90일 유지. 경미 수정은 기존 시점 유지, 게시물 교체는 재계산.
- 기본 기한: 제안 48시간, 자료 전달 후 제출 7일, 수정 2일. 캠페인별 변경 가능. 캠페인 마지막 게시일을 넘는 배정은 차단.
- 고객/제품 또는 브랜드 -> 채널 총수량/일정 -> 초안/문서 검토 -> 확정/프로젝트 자동 생성. 확정 중복 방지.
- 일정: 자료 준비/모집/제작/내부승인/주차별 게시. 준비기간 기본 7일, 캠페인별 조절. 합계 보존.
- 견적 기존 XLSX/도장 유지, PDF 출력. 별도 제안서 스타일 프로젝트 설명 PDF. 고객 문서에 내부 원가/원고료/추천료 제외.
- SENS + 원케이션 비즈니스 채널. 정보성 업무 알림 템플릿, 결과 조회/실패/재시도, 모집 광고 별도 자격 확인. 문자 대체 기본 OFF.

## 안전한 적용
기존 확정 계약과 과거 작업의 단가/일정은 자동 변경하지 않는다. 새 일정 정책은 신규 캠페인에 적용한다. 원고료 기본값은 코드 기준 블로그/클립 각 3,000원, 묶음 7,000원을 유지한다. 실제 송금은 기존처럼 운영자가 실행 후 기록한다. 채널 키/템플릿/운영 DB 마이그레이션 적용은 설정 완료 후 확인한다.
