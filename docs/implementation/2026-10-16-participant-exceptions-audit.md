# 참여자 예외 흐름 점검 (2026-10-16)

## 검증한 동작
- 제안 거절 시 배정하지 않으며 같은 슬롯에 새 제안 가능.
- 만료 제안은 수락 불가. 참여자/관리자 화면에 기간 만료 표시, 새 제안 등록 시 기존 제안 만료 처리.
- 제출·수정 기한 초과는 표시하고 늦은 링크 제출은 허용. 기한 초과만으로 자동 취소·자동 재배정하지 않음.
- 경미한 수정 후 같은 링크 재제출은 최초 제출 시각 유지. 주요 수정은 제출 시각/검수 가능일 초기화 후 새 제출부터 3일 재검수.
- 수정 기한 표시와 알림 준비/발송 재검증에 수정 기한을 사용. 수정 제출 후 활성 수정 경고 해제.
- 묶음 블로그만 검수 완료 → 개별 3,000원 부분 지급 → 미제출 클립 재모집 → 다른 참여자 배정·수락·자료 전달 → 링크 제출·검수·3,000원 지급.
- 캠페인 총수량 블로그 1건·클립 1건 유지. 첫 참여자는 완료한 작업과 3,000원 지급 기록 유지, 새 참여자는 미완료 클립만 조회.
- 추천료는 개별 500원씩 두 건 생성. 미완성 묶음에 1,200원 보너스를 적용하지 않음.
- 부분 지급 중복, 재모집 후 부분 지급 취소, 이전 참여자의 재배정 작업 제출 차단.
- 미완료 작업에 이미 게시 링크가 있으면 검수 또는 철회 확인 전 자동 재모집 차단.

## 수정
- 재모집 작업에 남던 이전 요청/제출/검수/수정 시각과 기한, 가이드 스냅샷, 품질 평가 초기화. 감사·요청 이벤트는 보존.
- 부분 완료로 종료된 수락 제안에 실제 지급액과 재모집 안내 표시. 거절/만료 이력에는 이 안내를 붙이지 않음.
- 관리자 제안 현황에도 시간 경과에 따른 만료 표시.
- 관리자 기한 초과 목록, 참여자 제출·수정 기한 초과 안내 추가.
- 재제출 후 수정 요청 경고가 계속 보이던 문제 수정.
- 기한 계산을 task-deadline 공통 함수로 통일해 수정 기한과 기존 제출 기한 혼동 방지.
