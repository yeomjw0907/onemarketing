# 대시보드부터 참여자 정산까지

## 대시보드

현황에서는 한국 날짜 기준 오늘 마감·지연, 검수·수정 대기, 승인 이후 미확인 게시물, 미지급 보수를 확인한다. 프로젝트별 다음 할 일을 누르면 해당 프로젝트의 자료/기획/검수/전달 탭으로 이동한다. 승인된 원고·이미지·영상 수와 블로그·클립 게시 확인 수를 함께 표시한다. AI 비용은 기존 실제 발생 비용 집계를 유지한다.

## 자료 체크리스트

프로젝트 → 자료에서 고객 작성 엑셀, 원본 사진, 제품 정보, 가격·혜택, 필수 문구, 금지 표현, 사용 권한을 관리한다. 사진/엑셀 파일 등록은 ‘접수’이며, 운영자가 검토한 뒤 ‘확인 완료’로 저장한다. 불필요한 항목은 필수를 해제하고 이유를 메모한다. 체크리스트는 준비도 표시이며 기존 기획 시작 조건을 대체하지 않는다.

고객에게 보낼 자료 요청문을 복사해 직접 전달한다. 고객 작성 엑셀은 체크리스트 및 자료실에서 다운로드할 수 있다. 고객이 작성한 파일은 고객 자료실에 업로드하고 프로젝트로 복사하거나 프로젝트 자료에 직접 등록한다. 사업자등록증은 고객 행정 자료로 보관하며 제작 자료·참여자 패키지에 포함하지 않는다.

## 참여자 게시 세트

1. 참여자 관리에서 블로그와 클립 계정을 각각 등록한다.
2. 프로젝트 → 전달·게시 → 새 게시 세트 배정에서 같은 프로젝트의 블로그 1개와 클립 1개를 선택한다.
3. 통합 보수는 기본 10,000원이다. 금액과 게시 지침을 확인하고 두 작업의 기존 개별 보수를 대체하는 데 체크한 뒤 생성한다.
4. 한 참여자는 한 프로젝트에서 하나의 세트를 맡는다. 5명 운영은 블로그 5개·클립 5개를 5세트로 배정한다. 원고당 이미지 3개와 클립 10초는 계약 단가의 작업 사양으로 설정한다. 이 기능은 기존 작업 수량이나 영상 사양을 변경하지 않는다.

동일 작업 중복 배정, 교차 프로젝트 연결, 지급/전달 후 묶기, 기존 다른 담당자를 새 참여자로 덮어쓰는 것을 차단한다. 세트에 묶인 작업은 담당자·계정·보수를 개별 변경하거나 개별 지급/취소할 수 없다. 전달 전에는 ‘세트 해제’를 눌러 기존 배정·개별 보수를 복원하고 새로 구성할 수 있다. 전달 후 변경 사항은 기존 승인본 보존 원칙에 따라 별도 작업으로 관리한다.

## 전달과 게시 확인

두 작업이 모두 승인되면 참여자 전달 ZIP을 다운로드한다. 패키지에는 해당 참여자의 두 작업 승인본, 이미지 순서, 승인 파일 목록, 프로젝트 마감일, 약정 보수, 게시 지침과 링크 제출 안내만 포함된다. 내부 원가·다른 참여자 파일·고객 행정 자료는 포함하지 않는다. 승인 뒤 파일이 변경되면 다운로드를 차단한다.

ZIP 다운로드는 전달 기록을 만들지 않는다. 실제 전달한 뒤 ‘실제 전달 완료 기록’을 누르고 각 작업에서 블로그·클립 링크를 등록·확인한다. 재전달 기록은 이미 확인한 게시 상태를 되돌리지 않는다. 외부 메시지는 자동 발송하지 않는다.

## 통합 보수와 원가

블로그와 클립이 모두 ‘게시 확인’이어야 세트 보수를 지급 완료로 기록할 수 있다. 두 작업의 지급 상태/지급일과 세트 지급 기록이 같은 트랜잭션에서 변경된다. 이 기능은 실제 송금을 실행하지 않으며 운영자가 송금 후 기록한다. 잘못 기록한 지급은 정산 마감 전에 세트 단위로 취소한다. 지급 후 게시 링크를 바꾸려면 먼저 지급 기록을 취소한다.

기존 원가·참여자 합계를 유지하기 위해 내부 원장에는 세트 총보수를 블로그 작업에 배분하고 클립 작업에는 0원을 배분한다. 화면에서는 세트 통합 보수로 표시하며 합계에 한 번만 반영한다. 5세트 × 10,000원이면 참여자 보수 총액은 50,000원이다. 계약 당시 예상 보수 스냅샷은 유지하고 현재 확정 보수/마진에서 배정 금액을 반영한다.

저장 형식은 기존 JSONB records의 posting_sets 종류와 프로젝트 materialChecklist 필드이다. 별도 테이블 마이그레이션은 필요 없다. 운영 데이터는 자동 배정하거나 변경하지 않는다.

## 슬롯 장바구니와 체험단 배정

새 계약은 슬롯 장바구니를 기본으로 사용합니다. 체험단 only(블로그 원고 1개·이미지 3장), 클립 only(10초 AI 영상 1편), 체험단 1 + 클립 1을 반복 담거나 종류별 수량으로 입력합니다. 묶음 5개는 블로그 5건·이미지 15장·클립 5건이며, 묶음 3개 + 클립 only 2개는 블로그 3건·이미지 9장·클립 5건입니다.

판매가는 선택한 기존 블로그·클립 단가의 합계이며 회차별 할인으로 조정합니다. 장바구니 구성은 계약의 진행 회차마다 적용되므로 한 번만 진행하려면 1개월·월 1회로 등록합니다. 단가·수량·보수는 계약 확정 시 스냅샷으로 보관합니다. AI 예상비용 미등록 상품은 시스템의 잠정 예산값을 사용하며 화면에 안내합니다. 기존 확정 계약과 프로젝트는 기존 구성을 유지합니다.

기본 보수는 블로그 3,000원, 클립 3,000원, 같은 슬롯의 블로그+클립 7,000원입니다. 묶음은 두 작업이 모두 게시 확인된 후 1회 지급하며, 원가에서는 블로그에 전액·클립에 0원을 배분해 중복 합산하지 않습니다. 단독 두 슬롯은 각 3,000원입니다. 체험단 프로필의 별도 약정액을 배정 시 반영할 수 있으며, 배정 저장 버튼에 적용 금액이 표시됩니다. 프로필을 수정해도 과거 작업 보수는 자동 변경하지 않습니다.

프로젝트의 **슬롯·배정** 탭 또는 **체험단 빠른 배정**에서 콘텐츠 제작 전후에 담당자를 선택합니다. 채널에 맞는 등록 계정을 확인하고 배정합니다. 같은 체험단에게 서로 다른 슬롯을 배정할 수 있지만 작업 자체를 중복 배정할 수는 없습니다. 실제 전달·게시·지급 이후에는 담당자를 바꾸지 못합니다. 기존 프로젝트의 게시 세트는 기존 메뉴에서 관리합니다.

## 카톡 파일 전달과 시간 기록

승인된 슬롯의 ZIP에는 해당 담당자의 원고 TXT·번호가 있는 이미지·영상·게시 안내만 포함됩니다. 개별 파일도 다운로드할 수 있습니다. **카톡 요청 문구 복사** 후 파일을 직접 첨부해 보내고, **실제 전달 완료 · 요청 시간 기록**을 누릅니다. 다운로드·복사만으로 전송을 기록하거나 카톡을 자동 발송하지 않습니다. 직접 보낸 시점의 기록을 운영자가 책임지고 입력합니다.

요청 시각, 게시 마감, 링크 접수 시각, 운영자 확인 시각, 수정 요청과 선택 품질 평가(1~5점)를 작업 및 체험단 이벤트 이력에 보관합니다. 재전달 시 최초 요청 시각을 덮어쓰지 않으며 같은 링크를 재확인해도 기존 확인 시각을 유지합니다. 게시 수정 요청 후에는 재검수하며 지급한 작업을 변경하려면 먼저 지급을 취소해야 합니다.

체험단 관리에는 이름·전화번호·이메일·채널별/묶음 기본 보수를 입력합니다. 속도 지표는 요청→링크 접수와 링크 접수→운영자 확인을 분리합니다. 기한 내 접수·미접수 지연·수정 요청 수·운영자 품질 평가를 표시하고 평균 접수 속도·품질순으로 목록을 정렬할 수 있습니다. 품질은 자동 추측 점수가 아닙니다. 미평가를 0점으로 계산하거나 시각이 없는 과거 이력으로 속도를 추정하지 않습니다. 링크 접수 시각은 운영자가 등록한 시각으로 실제 게시 시각과 다를 수 있습니다.
