# 게시 원고 교정·검증

관리자 **검수함** 또는 **프로젝트 → 제작·검수**에서 사용한다.

- **원고 생성**: 초안 작성 → 한국어 교정 → 별도 요청으로 원자료 대조 검증.
- **이 원고 교정·검증**: 현재 등록 원고를 초안으로 사용하고 교정부터 실행한다. 과거 원고를 자동으로 일괄 변경하지 않는다.
- 사실·체험·필수 요소 문제가 있으면 1회 수정 → 별도 재검증. 해결되지 않으면 원고와 지적을 저장하되 결과물 승인·자료 전달을 차단한다.
- 자동 검사 통과 후에도 운영자가 최종 승인한다. AI 대조는 사실의 정확성이나 법률 준수를 보장하지 않는다.

블로그와 클립 모두 첫 부분에 다음 문구를 자동 삽입한다. 원고료는 게시 후 검수·지급하는 구조이므로 지급 약정 사실을 표시한다.

> 이 게시물은 {브랜드}의 유료 광고로, 게시 대가로 원고료를 지급받기로 하고 작성했습니다.

수동 등록에도 적용하며 복사·다운로드·전달 파일에 동일하게 포함한다. 클립 설명은 광고 문구·공백·해시태그 포함 10~300자, 해시태그 최대 5개를 검사한다. 블로그 이미지 표식의 수량과 순서도 검사한다. **클립 영상 안의 광고 표시는 운영자가 별도로 확인해야 한다.** 이번 변경은 영상 생성 프롬프트를 변경하지 않는다.

현재 캠페인은 배송·방문 없는 소개형이다. 시식·사용·방문·구매 경험을 만들어내지 않고 확정된 제품 정보의 수치·조건·제한을 보존한다. 프롬프트 및 출력 검증은 `src/lib/copy-quality.ts`에서 버전 관리한다.

## 비교와 승인

원고 카드의 **초안·교정본 비교**, **주요 수정 사항**, **이전 등록 원고와 비교**에서 확인한다. 1회 수정을 거쳤다면 수정 전 교정본과 최초 검증 지적도 남긴다. 검증 결과는 원고 자산에 저장하며 참여자용 자료에는 게시 원고만 전달한다.

검증 이후 수동 수정은 기존 결과를 무효화하고 재검증을 요구한다. 제품 정보·캠페인 지침이 바뀌어도 기존 검사 통과로 승인할 수 없다. 실행 중 기존 원고나 기획이 바뀌면 덮어쓰지 않고 중단한다. 기존 수동 원고는 명확한 첫 부분 광고 표시를 확인해 운영자가 승인할 수 있으며, 별도 검증 버튼으로 새 절차를 적용할 수 있다.

## 실행·비용

신규 생성은 정상 3회, 수정 시 최대 5회 AI 호출이다. 기존 원고 교정은 정상 2회, 수정 시 최대 4회다. 관리자 화면의 작업 등록 시 기본 회당 예상 비용에 최대 호출 수를 곱해 예산을 예약하며 실제 비용은 각 공급사 호출 기록으로 합산한다. 보류 결과도 실제 호출 비용은 발생한다.

각 응답은 작업의 `copyCheckpoint`에 저장한다. 실행 시간 부족으로 재개할 때 완료된 단계를 반복 호출하지 않는다. 형식이 잘못된 검증 응답은 통과로 간주하지 않는다. 통신 결과가 불명확한 호출은 기존 작업 큐의 확인 절차를 따른다.
