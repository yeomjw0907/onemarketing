# GA4 문제 검색 자료 형식

검색은 브라우저 안에서 실행되며 외부 API나 번역 서비스로 질문을 보내지 않습니다.
영어·한국어 질문, 정답, 검색어, 해설을 색인하고 GA4 용어 대응어와
영문 한 글자 오타를 활용해 관련도순으로 보여줍니다. 질문 전체 일치를
우선하며, 검색 결과에서는 저장된 정답을 바로 표시합니다.

현재 데이터는 제공받은 `GA4_Exam_239_Complete_Verified.xlsx`의
`전체 문항 및 정답` 시트에서 가져왔습니다. 242행 중 가이드 3개(ID 38~40)를
제외한 **239문항**입니다. `data/source-questions.json`에 원문·보기 위치·정답·검수
상태를 보존하고 `data/import-summary.json`에 원본 파일 SHA-256과 가져오기 결과를 기록합니다.

`translations.ts`에는 한국어 검색용 질문·정답 요약이 있습니다. 반복 변형 문제는
요약을 공유하지만 영어 원문, URL과 ID는 각각 보존합니다. URL에서 복원한 142개
제목은 파일에 있던 상태 그대로이며 이를 화면에 표시합니다.

제공 파일의 검수 표시는 독립적인 재검증 결과가 아닙니다. 주의 문항은
화면에서 원본 상태·코멘트를 확인할 수 있습니다. 정답과 보기가 문장부호 제거 후에도
일치하지 않았던 6문항(ID 41, 42, 47, 59, 99, 158)은 2026-11-19에 각각의
원문에서 보기 순서와 정답 표시를 확인했습니다. `answer-verifications.ts`의
명시적 매핑을 통해 현재 표시되는 보기의 **4번**을 정답으로 연결합니다.
ID 59는 원문에서 보기 4개를 복원했으며 추출 엑셀의 기존 보기는 3번 위치입니다.
원본 JSON은 수정하지 않고 해당 레코드의 표시용 보기에만 보완을 적용합니다.
ID 158은 원문에 두 세트가 있어 현재 수록된 구용어 세트(Conversion events)의 4번을
사용합니다. 신용어 세트(Key events)는 2번이라는 설명도 확인 메모에 남깁니다.
ID 60~61의 빈 보기는 기존대로 유지합니다. 새로운 미확정 문항이 들어올 경우에는
여전히 `answer: -1`로 두고 번호를 추측하지 않습니다.

다시 가져오려면 번들 Python의 `openpyxl`을 사용합니다. 원본 엑셀은 수정하지 않습니다.

```powershell
python scripts/import-ga4.py C:/path/to/GA4_Exam_239_Complete_Verified.xlsx
```

새 자료의 검색용 레코드 필드는 다음과 같습니다. 원본에 없는 `correctAnswer`,
`answerKo` 등은 필요에 맞게 추가할 수 있습니다. 초기 연습문제는 회귀 테스트용으로
남아 있으며 실제 문제은행에는 섞이지 않습니다.

```json
{
  "slug": "unique-question-id",
  "topic": "보고서",
  "title": "한국어 질문",
  "titleEn": "English question",
  "options": ["첫 번째 보기", "두 번째 보기"],
  "answer": 0,
  "answerEn": "English answer",
  "searchTerms": ["다른 한국어 표현", "alternative English wording"],
  "explanation": "한국어 해설",
  "source": "https://example.com/source"
}
```

- `slug`는 중복되지 않는 URL 식별자입니다.
- `topic`은 `이벤트 수집`, `보고서`, `탐색`, `광고·기여분석`, `설정·연동`, `맞춤 데이터` 중 하나입니다.
- `answer`는 보기의 위치이며 첫 번째 보기는 **0**, 연결할 수 없으면 **-1**입니다.
- `correctAnswer`가 있으면 보기와 무관하게 해당 원문이 정답의 기준입니다.
- `titleEn`, `answerEn`, `searchTerms`는 선택 필드입니다. 양쪽 언어의
  질문과 정답을 함께 제공하면 원문 전체 검색과 한영 검색 정확도가 좋아집니다.
- 원문을 자동 번역하거나 임의의 문장을 이해하는 AI 검색은 아닙니다.
  새로운 전문 용어는 한영 질문·검색어를 자료에 넣어 대응합니다.
- 오답 보기로 검색해 잘못된 정답을 연결하지 않도록 보기 전체는 색인하지 않습니다.
- 주제와 북마크 필터는 검색과 함께 적용됩니다. 일치 결과가 없으면
  결과 없음으로 표시하며 정답을 생성하지 않습니다.
